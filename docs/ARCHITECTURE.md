# 아키텍처

## 전체 그림

이 저장소는 시온 아크 플랫폼의 **프런트엔드 프로토타입**이다. 최종 형태는 총회 신학통계과의
신학부 대시보드(제작 중)를 상위로 두고, 행정 지침 대시보드와 이 강사·전도사 AI 대시보드가
결합되는 통합 구조다. 그래서 처음부터 다음 경계를 지킨다.

- 본문 화면은 셸(`src/shell/**`) 없이도 동작하게 결합도를 낮게 유지 — 상위 대시보드 임베드 대비
- 세션 발급은 `src/lib/auth.tsx` 한 곳 — SSO 확정 시 이 모듈만 교체
- 데이터 접근은 `src/lib/store.tsx` 한 곳 — API 연동 시 이 모듈만 교체

## 디자인 시스템

시안: `Design/`(Next.js + shadcn 대시보드 템플릿, 녹색·화이트). 스택이 달라 컴포넌트를
그대로 쓰지 않고 **디자인 토큰과 레이아웃 패턴만** 이식했다.

- 색: `src/index.css`의 `@theme`에 oklch로 정의. `zion-*`(녹색 주색) · `gold-*`(보조 강조) ·
  `surface`/`ink`/`ink-soft`. **팔레트를 바꿀 일이 생기면 이 파일만 고친다**
- 사이드바는 흰 배경 + 활성 항목만 녹색 pill(그림자). 본문 배경은 옅은 녹빛 화이트
- 카드는 `rounded-card`(1rem) + 옅은 테두리 + hover 시 그림자 상승
- 전체 현황 첫 타일은 `StatTile accent`로 진한 녹색 강조 (시안의 강조 타일)
- 진입 애니메이션 `animate-slide-in-up`
- 앰버(`gold-*`)는 **우수 교안 지정 표시에만** 남겨 두었다 — 나머지 강조는 녹색으로 통일

### 반응형

현장에서 휴대전화로 자료를 여는 경우가 많아 좁은 화면을 1급으로 다룬다. 기준선은 `lg`(1024px).

- `lg` 미만: 사이드바가 **드로어**로 바뀐다 (상단 햄버거 → 슬라이드 + 오버레이, 화면 이동 시 자동 닫힘,
  열린 동안 뒤 본문 스크롤 잠금). `lg` 이상은 기존대로 272px 고정
- 목록+본문 2단 구성(자료실·교안·시리즈)은 `md` 미만에서 1단으로 쌓이고, 목록 높이를 42vh로 줄여
  본문이 화면 밖으로 밀리지 않게 한다
- 탭 줄은 `overflow-x-auto` + 항목 `shrink-0` — 좁아도 줄바꿈 없이 옆으로 넘긴다
- 출석 표는 표 자체만 가로 스크롤(`min-w-[560px]`) — 페이지 본문은 절대 옆으로 밀리지 않는다
- 검증: 전 화면에서 `document.body.scrollWidth === clientWidth` (가로 넘침 0) 확인

## 화면 구조 (정보구조 6개 카테고리)

| 카테고리 | 화면 | 경로 |
| --- | --- | --- |
| 현황 | 전체 현황 / 기수 현황(3탭) / 수강생 관리 | `/` `/cohort` `/students` |
| 강사 도우미 | **초등 · 중등 · 고등** 3단계 하위 묶음 — 각 과정의 강의자료 + 우수교안·지침·특강 | `/lessons?course=` |
| 자료실 | 표준 강의 자료 / 분반·보강 자료 / 우수 교안 | `/library` |
| 자료실 시리즈 | 요한계시록의 실상 / 천지창조 / 예수그리스도의 행전 | `/series/:id` |
| 전도사 도우미 | 분반·보강 자료 / 에니어그램 가이드 | `/library?tab=class_material` `/enneagram` |
| 공지사항 | 총회 공지 / 지파 공지 (하위 없는 단독 대주제) | `/notices` |
| 총회장님 어록 | 검색·뽑기 / 전체 주제 (하위 없는 단독 대주제) | `/quotes` |
| 말씀광장 | 온라인 성경 / 성경사전 (내부 뷰어) | `/external/bible` `/external/dictionary` |
| 천지일보 | 최근 이슈 / 종교·개신교 (내부 뷰어) | `/external/news` `/external/news-religion` |

**외부 자료** (`src/pages/ExternalViewer.tsx` + `src/content/external-links.ts`) — 링크가 늘면
`external-links.ts`에만 추가한다.

⚠️ **말씀광장·천지일보는 사이트 안에 띄울 수 없다.** 두 사이트가 `X-Frame-Options`로 다른 사이트
안에서의 표시를 막아 두어, iframe을 쓰면 실제 브라우저에서 "이 콘텐츠는 차단되어 있습니다"가 뜬다.
우리 쪽 설정으로 풀 수 있는 문제가 아니다. (개발용 인앱 브라우저는 이 정책을 무시해 통과한 것처럼
보이므로, **임베드 가능 여부는 반드시 실제 브라우저에서 확인한다**.)

그래서 뷰어는 자료 설명과 큰 바로가기를 담은 안내 화면을 내고 새 탭으로 넘긴다. 각 항목의
`embeddable` 플래그로 동작이 갈리며, 백엔드가 붙어 **서버 프록시**로 받아 오면 그때 플래그를 켜서
같은 화면 안에 띄울 수 있다.

내비 정의는 `src/shell/nav.ts` 한 곳. 새 화면은 여기에 항목을 추가한다.

내비는 3단이다 — **대주제 → (하위 묶음) → 항목**.
- 대주제는 **한 번에 하나만 열린다** (다른 대주제를 누르면 이전 것이 닫힘)
- 하위 묶음(초등·중등·고등)은 **여럿 동시에 열려 있어도 된다**. 열림 상태는 브라우저에 유지
- 하위가 없는 대주제는 `to`만 주면 접기 없이 바로 이동한다 (공지사항·총회장님 어록)

## 권한 모델

역할 7종 × 조직 범위 5단계 (전국/지파/교회/기수/분반). 판정 로직은
`src/lib/permissions.ts`에 모여 있고, 이는 서버 판정(memberships 대조)의 UI 미러다 —
백엔드 연동 후에는 서버가 최종 판정하며(범위 밖 403, 무세션 401) 프런트는 노출 제어만 한다.

| 기능 | 권한 |
| --- | --- |
| 자료실 등록·수정 | content_admin · headquarters_admin |
| 우수 교안 지정 | headquarters_admin |
| 총회 공지 작성 | headquarters_admin · content_admin |
| 지파 공지 작성 | 해당 지파 tribe_admin |
| 어록·영상 등록 | content_admin · headquarters_admin |
| 수강생·출결 조회 | 담당 배정 범위 (강사=기수 · 전도사=분반) |
| 열람(자료·공지·어록) | 로그인 전체 |

## 데이터 흐름 (현재 → 목표)

```
현재 (프로토타입)
  화면 ← useStore() ← localStorage (시드 포함)
  화면 ← cohort-mock.ts (가상 17명, 이중 분포)

목표 (운영)
  화면 ← useStore() ← app/api/library-materials · workspace-entries (D1)
  화면 ← attendance-adapter ← 읽기 전용 출결 시트 (추후 QR 시스템으로 어댑터만 교체)
```

수강생 키는 고유 ID가 없는 원본에 대비해 `교회|기수|분반|이름` 임시 키를 쓴다.
동명이인은 검토 목록으로 분리한다(원 저장소 규칙).

## Ask AI

`src/shell/AskAiBar.tsx` + `src/lib/search.ts`. 현재 로컬 키워드 검색으로 교안·에니어그램·
시리즈·자료실·공지·어록을 검색하고 **출처를 함께 표시**한다. AI API 연결 시에도:

- 검색 대상은 공통 교육 영역만 — 수강생 개인정보(차트·상담·출결 원문)는 입력 금지
- 답변에 출처 표시 유지
- aria-live 영역은 상시 렌더

## 대시보드 설계 지침

전체 현황은 **평균이 아니라 분포**를 보여준다. 예시 기수 실측: 출석률 97~100% 8명 /
50~96% 0명 / 13~49% 9명 — 중간이 없는 이중 구조가 첫 화면에서 드러나야 한다.
저녁 대면 비중(약 45%)은 보강 편성 신호로 함께 표시한다.
