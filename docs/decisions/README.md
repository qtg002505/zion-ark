# 결정 기록

회의·구두로 정해진 것을 원문 그대로 보관하는 곳이다. 코드와 문서가 어긋나면 **여기가 기준**이다.

| 문서 | 내용 |
|---|---|
| [ORG_CHART.md](ORG_CHART.md) | 조직 계층과 역할·범위 매핑 (`memberships`의 문서 기준값) |
| [2026-08-06_회의메모.md](2026-08-06_회의메모.md) | 메뉴 재편·화면 구성·자료실 이원화 결정과 미해결 질문 |
| [OPEN_QUESTIONS.md](OPEN_QUESTIONS.md) | **리드 답변 대기 목록** — 답이 나와야 착수 가능한 것 |

## 읽는 순서

작업을 시작하기 전에 `OPEN_QUESTIONS.md`를 먼저 본다. 손대려는 부분이 거기 있으면
답을 받기 전까지 착수하지 않는다 — 확정 전에 만들면 재작업이 된다.

## 원문은 고치지 않는다

회의메모와 조직도는 그 시점의 기록이다. 내용이 바뀌면 새 문서를 더하거나
`OPEN_QUESTIONS.md`를 갱신하고, 원문은 그대로 둔다.

반영 결과는 `../HANDOFF.md`와 `../../CLAUDE.md`에 적는다.
