### 소주제 접기 (2026-08-05)

긴 자료를 통글로 내리읽지 않도록 **소주제 단위 아코디언**을 넣었다 (`src/components/Accordion.tsx`).
- 경계 판정은 `splitSections()` (`src/lib/markdown.tsx`): `##` 헤딩 · `[핵심]`류 짧은 표제 · `◈ 결론`
- `#`(문서 제목)은 화면 제목과 겹쳐 버린다. `[확인 필요: 원문]` 같은 변환 메모는 본문에 남긴다
- 적용 화면: 시리즈 리더 · 강의 교안(초등 7항목 / 고등 4구획) · 에니어그램(유형별 항목)
- 기본 첫 항목만 펼침, "모두 펼치기/접기" 제공. 장을 옮기면 접힘 상태 초기화(`resetKey`)

**사이드바도 같은 방식**(`src/shell/Sidebar.tsx`) — 3단이다: 대주제 → 하위 묶음 → 항목.
- **대주제는 한 번에 하나만 열린다** (다른 대주제를 누르면 이전 것이 닫힘)
- **하위 묶음**(강사 도우미 › 초등·중등·고등)은 여럿 열려 있어도 되고, 열림 상태는
  `localStorage: zion_ark_nav_open_sub`에 유지된다
- 현재 화면이 속한 대주제는 자동으로 펼치고, 접었을 때는 점으로 위치를 알린다
- 하위가 없는 대주제(공지사항·총회장님 어록)는 `to`만 주면 접기 없이 바로 이동한다

### 주제로 어록 뽑기 (2026-08-05)

어록 화면 하단에 강의·모임용 어록을 주제로 모으는 도구를 넣었다 (`src/lib/quote-picker.ts`).
- "전도 관련 어록 뽑아줘" 같은 문장에서 주제어만 골라낸다 (불용어·조사 제거)
- ⚠️ 함정: 조사 제거 시 "전도"의 `도`를 조사로 오인한다 — 떼고 한 글자만 남으면 원래 낱말을 쓴다
- 관련도 = 주제(카테고리) 일치 > 본문 출현 횟수 > 연관어. 복수 주제어는 함께 만족할수록 위로
- 어록이 여러 주제에 중복 수록돼 있어 앞 40자로 중복을 걸러 낸다
- 결과는 원문 그대로 인용 + 출처(주제·번호) 표시, 전체 복사 지원. 요약·재작성하지 않는다

어록 화면 구성: **상단 = 검색·뽑기 / 하단 = 전체 주제 아코디언**(주제 98개, 눌러서 펼침).
사이트에서 등록한 어록도 아코디언 첫 항목("사이트 추가 등록")으로 같은 자리에서 본다.
주제 하나에 어록이 많으면(최대 148건) 주제 안에서 30건씩 나눠 보여 준다.

- 클로드 계정이 없는 사람도 보게 하려면 공유 창에서 ① 최신 버전을 지정하고 ② 공개 범위를

- ⚠️ 함정 둘, 둘 다 해결해 둠:
  1. 정적 호스팅에는 서버 라우팅이 없다 → `.env.preview`의 `VITE_ROUTER=hash`로 해시 라우팅 빌드

     `data:` URI로 싣는 방법도 되지만 **공개 공유가 거부되므로 쓰지 않는다**
- 로컬 확인: `.claude/launch.json`의 `zion-ark-share-preview` (포트 4173)
- 운영 배포에는 쓰지 않는다 — 그때는 `dist/`를 그대로 올린다

### 새 기능 3종 (2026-08-05)

**① 강의 자료 모으기** (`/compose` · `src/lib/compose.ts`)
주제 하나로 교안·시리즈·어록·에니어그램·자료실을 한 번에 훑어 종류별로 묶는다.
- 강 전체가 아니라 **항목·소주제 단위로** 잡는다 (그 대목만 인용하기 위해)
- 원문 그대로 인용 + 출처 표기, 요약·재작성하지 않음. "강의안으로 복사" 지원

**② 현장 기록** (`src/components/LessonNotes.tsx` · 교안 화면 하단)
강의를 해 본 사람이 남기는 기록(많이 나온 질문 / 주의할 점 / 잘 통한 방법).
교리 원문은 그대로 두고 경험만 옆에 쌓는다 — 다음에 같은 강을 맡는 사람이 먼저 본다.
- 저장 구조는 원 저장소 `content_library_notes` 계약에 맞춘 `LessonNote`
- 입력 폼에 "수강생 이름·개인 사정은 적지 않는다" 안내를 둔다

**③ 관찰 필요** (`/signals` · `src/lib/attendance-signals.ts`)
누적 출석률만 보면 **아직 높은 사람의 최근 흔들림**이 가려진다. 최근 8주 변화를 본다.
- 신호: 연속 결석 · 보강 미이행 · 출석 시간대 변경 · 미입력
- ⚠️ **사람을 판정하지 않는다**(불변식 4). 점수를 내지 않고 관찰된 사실만 적으며, 연락 여부는 담당자가 정한다
- 목업에 최근 8주 출결(`recentWeeks`)을 넣어 "지금 갈리는 중인 4명"이 드러나게 했다.
  실연동 시 이 필드는 출결 시트에서 그대로 온다
- ⚠️ 실데이터 투입 전 **시범 로그인 정리와 권한·기록 설계가 선행**되어야 한다

### 반응형 · 크로스 브라우징 (2026-08-05)

PC·Android·iOS에서 같게 보이도록 **공통 규칙을 `src/index.css`에 모았다**.
상세는 `docs/RESPONSIVE.md`. 화면 파일마다 되풀이하지 않는다.

밖에서 재현되던 증상과 원인:
- **텍스트가 세로로 찢어짐** — flex·grid 자식의 `min-width: auto` 때문에 한 칸이 부모를 밀어내고
  옆 칸이 찌그러진다. `:where(.flex,.grid) > * { min-width: 0 }`로 전역 해제
  (줄면 안 되는 요소는 `shrink-0`이 그대로 이긴다)
- **iOS에서 입력칸 누르면 레이아웃 틀어짐** — Safari는 입력 글자가 16px 미만이면 화면을 확대한다.
  터치 기기에서만 입력 요소를 16px로 올렸다(디자인상 12~13px보다 커지지만 확대되는 쪽이 더 나쁘다)
- **iOS 가로 모드에서 글자만 커짐** — `-webkit-text-size-adjust: 100%`
- **목록이 화면 밖으로 넘침** — iOS는 `vh`를 주소창까지 포함해 잰다.
  `.doc-list-scroll` 유틸이 `dvh`를 우선 쓰고 미지원 시 `vh`로 되돌아간다
- 한글 줄바꿈은 `word-break: keep-all` + `overflow-wrap: anywhere` **둘 다** 필요하다

검증: 320·375·768·1280 폭에서 전 화면 가로 넘침 0, 세로 찢김 0.
공백 없는 긴 URL·긴 한글 문장을 넣어도 영역 안에서 줄바꿈됨을 확인했다.
⚠️ **iOS 특유 동작은 데스크톱 시뮬레이션으로 재현되지 않는다** — 실기기 확인이 필요하다.

### 보류 — 말씀광장·천지일보 사이트 안 표시 (백엔드 프록시 필요)

리드 요청은 "사이트 안에서 보기"였으나 두 매체가 `X-Frame-Options`로 외부 표시를 막고 있어
현재는 **새 탭으로 연다**(2026-08-05 리드 결정). 사이트 안 표시는 아래 조건이 갖춰지면 가능하다.

**착수 조건**: 백엔드(API 서버)가 붙어 우리 도메인에서 요청을 중계할 수 있을 때.
프런트 전용인 지금은 불가능하고, 정적 프리뷰(아티팩트)에서도 불가능하다.

**방법**: 서버에 중계 경로(예: `/api/external/:id`)를 두어 대상 페이지를 받아 우리 도메인으로
내려준다. 브라우저가 같은 출처로 보므로 iframe에 담긴다. 확인·주의할 점:
- 상대 매체 이용약관에 중계·재표시가 걸리지 않는지 먼저 확인 (법무·리드 판단 사항)
- 상대 페이지의 상대경로 자원(css·js·이미지)이 깨지지 않게 base 처리 필요
- 캐시를 두어 상대 서버에 부담을 주지 않게 한다

**작업이 가능해지는 시점에 리드에게 알린다** — 백엔드 연동 착수 세션에서 이 항목을 확인할 것.
