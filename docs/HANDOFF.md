  기록(점검표 갱신·보강 완료 전환)하게 할지, 시트 병행 기간을 둘지 리드가 정한다.

  익명화·집계 대상이다 — 실데이터 투입은 시범 로그인 정리가 선행이다

## 지금 구조에서 알아야 할 것

- **다크 모드는 화면 파일을 한 곳도 안 고치고 넣었다** (2026-08-11).
  `src/index.css`의 `[data-theme="dark"]`가 팔레트 변수를 갈아 끼운다.
  ⚠️ **진한 배경으로 쓸 수 있는 클래스가 정해져 있다** — `CLAUDE.md` 화면 규칙의 목록을 본다.
  목록 밖 단계를 배경에 쓰면 다크에서 하얗게 뜬다
- **데이터는 브라우저 안에만 있다** (localStorage). 같은 브라우저에서 재로그인하면
  그대로 남지만 **다른 기기·브라우저에서는 안 보인다** — 백엔드가 붙어야 풀린다
- **음악은 팀 공유 링크(Pages)에서만 들린다.** 아티팩트 프리뷰는 단일 HTML이라 음원을
  넣으면 16MB 제한을 넘어 일부러 뺐다
- **시범 로그인은 인증이 아니다.** 브라우저 콘솔에서 `localStorage`를 고치면 아무 역할이나
  될 수 있다 — 실데이터 투입 전 정리가 선행이다
- **번들이 2.9MB(gzip 870KB)다.** 현장에서 휴대전화로 여는 사이트라 라우트별 코드 분할을
  검토할 때가 됐다. 빌드가 매번 경고를 낸다
- **자동 테스트가 0건이다.** 도움됨 중복 클릭·타인 글 수정 차단 같은 것을 세션마다 손으로
  확인하고 있다 — 다음 사람이 회귀를 못 잡는다
