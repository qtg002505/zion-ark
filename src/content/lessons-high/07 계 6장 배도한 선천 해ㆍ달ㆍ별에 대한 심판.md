< 계 6장, 배도한 선천 해ㆍ달ㆍ별에 대한 심판 >
[핵심]
- 예수님 : 인을 떼심 → 네 생물 들어 배도한 일곱 금 촛대 장막의 목자, 성도들 심판
- 심판받는 이유 : 계 2~3장 회개의 편지 → 회개하지 않았기 때문
[서론]
- 제목 : 배도한 선천 해ㆍ달ㆍ별에 대한 심판
- 예수님 : 계 6장 봉한 책의 인, 하나씩 떼실 때
→ 하나님 보좌 앞 네 생물 출현
→ 말과 탄 자 : 배도한 선민 심판
인을 떼실 때마다 나타나는 사건, 누가, 언제, 어디에서, 무엇을, 어떻게 하여 생긴 결과인가
[본론]
- 계 6:1~2 예수님 : 첫째 인 → 흰 말, 탄 자
- 활 : 심판하는 말씀
- 사건 현장 : 하나님의 선민의 장막 곧 장막성전(온 세계 X)
- 활을 쏘시는 이유
: 예수님을 배반 → 사단의 족속과 하나가 되었기 때문(사 2:6, 애 2:1~6)
- 이기고 또 이기려고 하는 것
: 초림 때 마귀를 이긴 것(요 16:33)
→ 재림 때에도 이기신다는 것
- 계 6:3~4 둘째 인 → 붉은 말, 탄 자 : 큰 칼
- 탄 자가 받는 큰 칼 : 하나님의 말씀(엡 6:17)
- 화평이 제해지는 땅
: 성령 → 육체로 돌아간 배도한 선민 장막(마 10:34)
- 화평을 제하고 서로 죽게한다는 것
: 배도한 장막 성도들 : 시험 빠짐 → 서로 미워함
⇒ 멸망자에게 내어주며 서로의 영 죽게 함(마 24:10, 마 10:21)

- 계 6:5~6 셋째 인 → 검은 말, 탄 자 : 저울
- 탄 자가 가진 저울 : 믿음과 행실을 달아보는 하나님의 말씀(잠 24:12)
- 한 데나리온 밀 한 되 보리 석 되
: 배도한 장막 가운데 주님의 말씀에 합당한 자들이
겨우 밀 한 되, 보리 석 되에 빗댈 정도로 적다는 것
- 감람유, 포도주는 해치 말라
: 증거의 말씀, 예수님의 말씀을 가진 자들은 해하지 말라(계 11:3~4, 요 15:1)
- 계 6:7~8 넷째 인 → 청황색 말, 탄 자 : 사망
- 탄 자의 이름이 사망인 이유 : 죽이라는 명(命)을 받았기 떄문(겔 9:4~6)
- 음부가 그 뒤를 따르는 이유 : 죽임 당한 자들을 데려가기 위함
- 땅 사분의 일의 권세 : 배도한 일곱 금 촛대 장막 성도 1/4 죽이는 권한
- 검(劍) : 심판의 말씀(엡 6:17)
- 흉년 : 말씀이 없는 영적 빈곤(암 8:11)
- 사망 : 영을 죽이는 것
- 땅의 짐승 : 음부에 속한 멸망자
→ 바다에서 나온 짐승과 하나되어
하늘 장막 짓밟고 666표를 한 자(계 13:11, 계 17장)
- 계 6:9~11 다섯째 인 → 제단 아래 순교자들 : 피의 신원(억울하게 죽은 한) 호소
- 제단 아래 : 하나님 보좌 앞 네 생물이 있는 곳
- 땅에 거하는 자들 : 멸망자들
- 심판해달라고 하는 이유 : 멸망자 심판
→ 사단의 정체 드러내는 일 = 사단을 심판하는 일
- 순교자들에게 흰 두루마기 주신 것
: 순교자들의 행위가 옳았음을 인정해 주는 것
- 동무 종들과 형제들의 실체
: 배도한 일곱 금 촛대 장막 목자와 성도들
- 그 수가 차는 때
: 1/3씩 죽임을 당하는 때(계 8, 9, 12장)

- 계 6:12~17 여섯째 인 뗄 떄의 사건
- 큰 지진
: 일곱 금 촛대 장막 성도들의 마음이 크게 흔들리는 것
- 해, 달, 별이 어두워지고 떨어진다는 것
: 하늘 장막 목자, 전도자, 성도가 말씀의 빛 발하지 못하고 이방 소속이 된다는 것
- 하늘이 떠나간다는 것
: 영계 성령 떠나감 → 선민의 장막 : 원래 있던 곳 → 이방 소속 이전함
- 각 산, 섬 제자리에서 옮겨짐
: 일곱 금 촛대 장막 지교회들, 하나님 소속 → 이방 소속 이전됨(렘 6:12~13)
- 땅의 임금들, 왕족들, 장군들, 부자들, 강한 자들, 각 종과 자주자
: 목자(중진) ~ 성도에 이르기까지 성령 → 육으로 돌아간 장막 사람들
- 굴, 산, 바위틈에 숨는 것
: 음부의 조직인 이방 교단과 목자의 소속이 되는 것(사 2:19, 계 17:9, 신 32:31)
- 예수님께서 함께하시던 일곱 금 촛대 장막의 성도들 쫓겨나
이방의 소굴로 들어가게 된 원인
= 이들이 하나님과의 언약 : 아담같이 어김(호 6:7) + 이방 신 섬김
- 이들의 생령 → 멸망자의 교단 : 1/3씩 죽임 당함(계 8, 9, 12장)

◈ 결론
- 계 6장 : 신약 성경에 약속한 말세의 사건
영적 이스라엘 곧 기독교 세계의 모든 목자와 성도를 끝내는 종말의 사건
- 계 6장 成 → 예수님 선천(先天)의 역사 : 끝
⇒ 이 일 후 후천(後天) 세계 : 영적 새 이스라엘 창조(계 7장 약속)
- 천국, 영생 신앙하는 신앙인 : 말씀 믿고 인정 → 영적 새 이스라엘 12지파 가족 되어야 함
