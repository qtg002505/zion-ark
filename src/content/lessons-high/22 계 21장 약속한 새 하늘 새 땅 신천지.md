- 하나님, 천국 임해 오심 → 사망 끝, 영생 시작
- 하나님 : 목적 달성 ⇒ 안식 들어가심
[서론]
- 제목 : 약속한 새 하늘 새 땅 신천지
- 계 21장 처음 하늘 처음 땅, 바다 없어진 후 → 새 하늘 새 땅 창조
- 하나님, 영계 천국 거룩한 성 새 예루살렘 → 새 하늘 새 땅 신천지 : 임해 오심
⇒ 신천지 사람들 : 영생 O
- 하나님 → 이기는 자 : 아들 ⇒ 모든 유업 상속하게 해주실 것 약속
[본론]
- 계 21:1 처음 하늘 처음 땅 없어짐
- 처음 하늘 : 모세 때 하나님이 보여 주신 하늘에 있는 예루살렘(히 8:5)
- 처음 땅 : 육계의 육적 예루살렘
- 새 하늘 = 영계의 새 예루살렘
① 육적 예루살렘 언약 어김
② 요 14:2~3 처소, 순교한 예수님과 12제자 → 기초석
- 새 땅 = 육계의 새 예루살렘
계 7장 영적 새 이스라엘 12지파(하늘 成 → 땅 창조)
- 처음 하늘 처음 땅
: 범죄한 아담 세계 ~ 새 하늘 새 땅 출현 이전까지의 세계
나라의 본 자손 전통 교회
- 새 하늘 새 땅
: 계시록 성취 때 창조된 새 나라 새 민족 신천지 12지파
- 바다도 다시 있지 않더라 = 멸망자들 → 심판 받아 없어질 것
단 7:3, 17 바다 = 세상
멸망자와 그들이 주관한 바벨론 세상
계 2~3장, 13장 니골라당, 일곱 머리 열 뿔 짐승
= 마지막 때 바다 곧 멸망자의 실상
- 계 21:3~4 하나님의 장막 → 사람들 : 함께 있게 됨
: 예수님과 12제자 창조 → 영계 천국 ⇒ 신천지 12지파와 하나가 되는 것
창 6장 떠나가신 하나님 6천 년 만에 다시 돌아와 함께하시게 됨
⇒ 신천지 : 사망 X, 영생 이루어짐
- 계 21:5~6 만물을 새롭게 하시는 이유
: 하나님 떠나가신 후 만물 → 사단의 모양, 형상 변질
⇒ 다시 하나님의 모양, 형상 소성하는 것
- 알파와 오메가 : 처음과 나중, 시작과 끝
⇒ 하나님 : 예언하시고 이루신다
요 19:30 구약 예언 → 초림 예수님 : 다 이루심
계 21:6 신약 예언한 것 → 오늘날 다 이루어짐
- 계 21:7 이긴 자 : 이것들 유업 얻음 → 하나님의 아들이 됨
: 계 2~3장, 12장 사단 소속 용의 무리와 싸워 이기는 자 출현
하나님 → 이긴자 : 약속하신 12가지 복 주심
하나님의 아들을 삼아 주심
⇒ 이긴자 꼭 만나 : 영생의 양식 얻어 먹어야 함
- 계 21:8 둘째 사망에 들어가는 자들
- 둘째 사망 : 육신이 죽고 난 후 영혼이 받게 될 지옥 형벌
- 둘째 사망자들
① 실상 믿기를 두려워 하는 자들
② 성취 때 이룬 실상 믿지 않는 자들
③ 거짓말로 증거하는 자들
- 계 21:9~10 신부 곧 어린양의 아내
: 하늘에서 내려오는 거룩한 성 새 예루살렘(계 21:10)
- 아내라고 하는 이유 : 예수님 → 영계 천국의 기초석이 된 제자들 : 영적 아내의 입장
말씀의 씨
- 거룩한 성 보여주신 이유
: 마 6:10 본 그대로 이 땅에 창조하게 하기 위함

- 계 21:11~21 거룩한 성 새 예루살렘의 모습, 순교한 영들의 조직체(천국)
열두 진주 문, 12지파, 12기초석
: 벧전 2:4~5 진리의 말씀 받은 제자들 → 보석, 기초석 : 영계의 나라
- 영계의 천국 → 이 땅 成 : 신천지만 가지고 있는 것
: 12지파, 진리의 말씀 나옴 = 천국이라는 증거
- 1만 2천 스다디온 장, 광, 고 같음
: 각 지파 인 맞은 자 1만 2천 명씩 총 144,000명 창조
- 계 21:22~27 하나님, 어린양 = 성전
- 하나님의 영광 : 빛, 어린양 → 등이 되심
: 이 성, 목자와 전도자의 빛 필요 X
하나님의 말씀이 없는 무지(밤) X
- 사람들 : 만국 영광, 존귀 가지고 들어옴
: 생명책 기록된 자들 → 천국 들어올 수 있음
⇒ 천국 호적부 생명책 기록되어야 함

- 하나님 : 6천 년 만에 이 땅에 돌아오시는 회복의 역사 이루심
- 보고 들은 자, 약속된 유업을 받는 자 : 예수님의 약속한 목자 이긴자
- 하나님 : 예언하신 것 반드시 이루심
⇒ 성경대로 이룬 신천지 하나되어 영생의 복 받자
