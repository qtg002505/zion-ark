< 계 19장, 영육 어린양의 혼인 잔치 >
[핵심]
- 어린양의 혼인 잔치 집 : 증거장막 성전
→ 혼인 잔치 배설, 영/육 초대
- 지상 만민 : 어린양의 혼인 잔치 집( = 이긴자가 인도하는 증거장막 성전) 소속 ⇒ 구원
[서론]
- 제목 : 영육 어린양의 혼인 잔치
- 사건의 현장 : 영육 어린양의 혼인 잔치 집
※ 실체 : 계 15장 증거장막 성전
- 성취 시기 : 계 18장 바벨론 심판 후
- 주 재림 때 예수님의 신부가 되기를 원하고 깨달아 → 천국, 영생 소망 이르자
[본론]
- 계 19:1 ‘이 일 후’
- ‘이 일’ : 계 18장 귀신의 나라 바벨론 심판함 → 마귀와의 결혼 끝내는 사건
- ‘이 일 후’ 계 18장 사건 成 → 계 19장 어린양의 혼인 사건 成
: 중요한 시점 알리는 말씀
- 계시록의 대조장 : 계 6, 7장, 계 13, 14장, 계 18, 19장
- 하늘에 모인 허다한 무리
: 계시록 말씀과 사건 깨달아 하나님 앞으로 나아온 자들
- 하늘 : 계 13:6 처음 하늘(장막 성전) 배도 → 멸망 후
⇒ 열린 계 15장 새 하늘 증거장막 성전
- 할렐루야 구원, 영광, 능력 → 하나님께 있도다 외치는 이유
: 어린양 → 용과 싸워 이기심
⇒ 바벨론 사로잡혀 있는 백성들 빼내시고 구원하셨기 때문
- 하나님, 곧 전능하신 이가 통치하시도다 외침
: 계 18장까지 : 마귀가 통치하는 시대
계 19장 : 하나님께서 통치하시는 구원의 시대가 됨 알림

- 계 19:7~8 어린양의 혼인 기약 : 예수님 외 다른 신과 교제 X, 약속하는 것
- 혼인 기약 이전 : 계 18장 만국 → 마귀와 결혼
- 말씀이 나와는 무슨 상관인가 깨달음
→ 하나님의 뜻대로 순종하시는 하나님의 가족이 되자
- 혼인 잔치 주인공 신랑 : 어린양 예수님
혼인 잔치 예비한 어린양의 아내 : 신약의 약속의 목자 새요한(계 22:17)
- 빛나고 깨끗한 세마포 : 성도들의 옳은 행실
마 22:1~14 어떤 임금 : 아들을 위하여 베푸는 혼인 잔치 비유
- 혼인 잔치 집 증표
마 22:4 혼인 잔치 : 하나님의 소와 살진 짐승 = 배도자들, 멸망자들
- 혼인 잔치 집 자격 = 등, 기름, 예복
마 25:1~13 등, 기름
마 22:11~14 예복
- 계 19:11~16 백마 탄 자 : 예수님(충신과 진실, 만왕의 왕, 만주의 주)
- 백마 : 예수님 → 대언자 삼은 새요한
- 백마 탄 자 입 → 이한 검과 철장 : 심판의 말씀(계 1:16, 계 2:27)
- 하나님과 마귀의 군대
① 강철 백마부대 : 하나님 보좌 앞 천천만만의 영들, 혼인 잔치 집 모인 성도들
② 마귀의 군대 : 계 9장 이만만의 영, 바벨론 무리
- 결과 : 하나님의 강철 백마부대
→ 계 18장 바벨론 패잔병들 ⇒ 계 19장 소탕
- 계 19:17~21 천사 : 공중의 새들 → 큰 잔치 모음
: 천사 → 순교한 영들 : 어린양의 혼인 잔치에 청하는 것
- 신약의 약속의 목자 이긴자 → 성도들
: 어린양의 혼인 잔치 집으로 불러모으고 있음
- 배불린다는 것
: 혼인 잔치 집 모인 순교한 영들, 12지파 성도들
→ 배도자들, 멸망자들 심판하는 증거의 말씀 듣고 마음이 만족케 되는 것

[결론]
- 주 재림 때 어린양의 혼인 잔치 집
: 계 18장 바벨론 심판 후 출현하는 새 하늘 증거장막 성전
- 모인 영, 육 : 순교한 영들, 12지파 성도들
- 예수님의 신부 → 혼인 잔치 참여하기 위한 자격
- 배도자들, 멸망자들 증거하는 곳
- 등, 기름, 예복 준비
- 신약의 약속의 목자 이긴자 새요한 → 등, 기름, 예복 참 뜻을 깨닫고 준비
⇒ 천국 혼인 잔치 참여하는 자 되자.
