< 계 11장, 두 증인과 일곱째 나팔 >
[핵심]
1. 일곱째 나팔 불림 : 세상 나라 → 하나님 나라 : 부활, 영생 이루어짐
2. 천국, 영생 얻기 위해서 일곱째 나팔 새요한 만나 예수님의 계시 받아야 함
[서론]
- 제목 : 두 증인과 일곱째 나팔
- 마지막 일곱 째 나팔 불릴 때 : 세상 나라 → 하나님 나라 놀라운 일 있음
천국을 소망하는 신앙인 → 일곱째 나팔 반드시 알아야 함
→ 이를 알기 위해 계 11장 말씀 안으로 들어가보자
[본론]
- 계 11:1~2 천사 : 지팡이 같은 갈대 → 요한
- 척량하라
: 하나님의 성전, 제단, 그 안에서 경배하는 자들
- 척량하지 말라
: 성전 밖 마당 → 이방인에게 주었음
- 지팡이 : 의지하는 도구 = 요한을 돕는 영적 베필
- 갈대 : 연약한 자
∴ 실체 : 계시록이 이루어지는 오늘날,
새요한을 돕는 장막성전의 성도 중 한 사람
- 척량하라고 한 하나님의 성전
: 선민의 배도 → 멸망 받는 현장
⇒ 이기고 나온 소수의 무리
= 이긴자를 따라 나와 하나되어 예배드리는 사람들
(고전 3:16 사람 = 하나님의 성전)
- 이들의 믿음, 지식의 분량
: 새요한, 돕는 베필과 함께 척량하는 것
- 척량하지 않는 성전 밖 마당
: 계 13장 짐승이 들어간 장막성전
→ 배도, 회개하지 않았기 때문 ⇒ 42달 동안 짓밟힘

- 멸망의 기간
구약의 육적 이스라엘 → 이방 바벨론에게 70년 동안 멸망당함
오늘날 육체로 구원받도록 42달로 감해주심(마 24:22 택하신 자들 : 육체의 구원)
- 계 11:3~4 요한, 지팡이 같은 갈대
- 이 땅 주 앞에 섰는 두 감람나무와 두 촛대
= 이 땅에서 주를 모신 두 증인
= 하나님 보좌 앞 등불의 영 함께하는 자
- 두 증인 : 여러 재앙을 땅에 내림
① 굵은 베옷 → 죽은 행실 회개시킴
② 장래 일 1,260일 동안 예언
③ 입 → 불 나와 심판
④ 하늘 닫아 비오지 못하게 함
⑤ 물 → 피 되게 함
- 두 증인 증거 마칠 때
→ 무저갱 짐승에게 죽임을 당하게 됨
= 사단 소속 거짓 목자들
① 두 증인 → 거짓 목자들 : “너희가 멸망자다!” 해야 할 말 다하며 증거
이들 → 두 증인 : 영적으로 죽이는 것
② 두 증인의 사명 : 증거하는 일
짐승 : 세상 권력 → 증거하지 못하게 함
= 영적 죽임 당한 것
③ 큰 성 곧 이방이 된 장막성전
: 영적 부패한 소돔, 애굽, 예수님께서 십자가에 못 박히신 곳 같음
④ 사람들 → 두 증인 시체 : 사흘 반 동안 목도
⇒ 무덤 장사하지 못하게 함
= 두 증인을 자기 교단에 가입시키지 않는 것
⑤ 두 증인 : 심판하는 말 그침 → 기뻐하는 말 자기들끼리 선물처럼 주고 받음
⇒ 두 증인 증거하지 못하게 된 것을 조롱하는 것

- 두 증인 → 사흘 반 지나 하나님의 말씀(생기) 들어감으로 살아남
⇒ 구름을 타고 하늘로 올라감
① 하늘로 올라간 것 : 두 증인의 영 → 하나님 계신 곳 인도 받는 것
∴ 육체 → 이 땅의 하늘 : 장막성전으로 가는 것
② 두 증인의 부활 원수 사단 무리들 두려워 함,
마음이 흔들리는 큰 지진 있게됨
- 계 11:15~19 이방에게 주어진 42달 끝
일곱째 나팔 : 세상 나라 → 하나님 나라 ⇒ 예수님 세세토록 왕 노릇 하심
- 일곱째 나팔
계 10:7 일곱째 나팔 : 하나님의 비밀
→ 그 종 선지자들에게 전하신 복음과 같이 이루어짐
고전 15:51~54 부활, 영생 → 이 땅에서 이루어짐
- 일곱째 나팔 소리
: 순교자들 → 신령한 몸 부활
살아 있는 우리 → 변화 : 영원한 생명
- 부활과 영생에 이르기 위해 일곱째 나팔 소리 들어야 함
- 일곱째 나팔 : 오늘날 예수님의 계시를 받아 전하는 약속의 목자 새요한
∴ 새요한 : 계 10장 열린 책의 말씀 받고 계시록 전장의 사건을 보고 들은 증인
- 언약궤, 번개, 음성, 뇌성, 지진, 큰 우박이 있는 하나님 성전 열림
: 오늘날 하나님 나라 신천지예수교 증거장막성전 창립
[결론]
- 계 11장 : 두 증인 → 증거, 희생당한 후 부활
⇒ 일곱째 나팔 불게 됨
세상 나라 → 하나님의 나라 : 부활, 영생 이루어질 것 약속한 말씀
- 이 말씀 이미 이루어짐
오늘날 모든 인류 : 일곱째 나팔 새요한 만나
① 예수님 계시 받아야 함
② 하나님과 그리스도의 나라가 되어야 함(세상 나라 X)
