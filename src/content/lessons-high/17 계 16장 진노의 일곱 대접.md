< 계 16장, 진노의 일곱 대접 >
[핵심]
- 계 15장 증거장막 성전 이긴자들 : 대접
→ 계 16장 배도자, 멸망자 심판하는 내용(마지막 재앙)
[서론]
- 제목 : 진노의 일곱 대접
- 일곱 대접의 재앙 : 계시록 세 가지 재앙 중 마지막 재앙
일곱 대접 : 하나님의 진노 담겨 있음
실상은 누구, 어디서 어떻게 심판
심판의 결과는 무엇인가
[본론]
- 일곱 대접의 재앙 : 배도자, 멸망자 심판하는 재앙
- 대접을 쏟는 장소 : 계 13장 하늘 장막
멸망자가 들어와있는 배도자의 장막
- 일곱 대접 : 계 12장 용의 무리와 싸워 이기고
계 15장 증거장막 성전에 모인 이긴자들
- 대접으로 삼으신 이유 : 계 12, 13장 배도, 멸망의 현장에서 보고 들었기 때문
- 계 16장 심판 : 계 8~9장 멸망자 → 배도자 행한 일
갑절로 되갚아 주시는 심판(계 13:10, 계 18:6)
- 첫째 대접 → 땅 : 악하고 독한 헌데
: 짐승에게 경배한 장막 성도들에게 쏟아진 재앙
- 악(惡) : 멸망자들의 교리 인정한 행위
- 독 : 사단의 교법 → 성도들 받아들임
- 헌데 : 진노의 말씀 → 배도 행위 드러나 부인할 수 X ⇒ 마음의 상처
- 둘째 대접 → 바다 : 바닷물 → 죽은 자의 피 ⇒ 바다 가운데 모든 생물 죽음
: 하나님의 진노의 말씀 → 멸망자들 : 거짓 목자들의 교리
⇒ 비진리(생명 X)임 드러남, 성도들 더 이상 거짓 교리 듣지 못하게 됨

- 셋째 대접 → 강, 물 근원 : 물 → 피 ⇒ 대적에게 마시게 함
: 하나님의 진노의 말씀 → 멸망자 거짓 목자, 전도자의 교리
⇒ 비진리(생명 X) 드러남 ▶ 멸망자들에게 증거 : 직접 듣게한 사건
- 물 근원 : 목자
강 : 전도자
- 넷째 대접 → 해 : 불 ⇒ 사람 태움
: 하나님의 진노의 말씀 → 거짓 목자 : 회개 X, 진노의 말 ⇒ 장막 성도들 더욱 괴롭힘
- 해 : 사단의 거짓 목자
∴ 실상 : 청지기 교육원 ‘땅 씨’
- 다섯째 대접 → 짐승의 보좌 : 나라가 어두워짐, 아픈 것과 종기
: 멸망자들의 교리 → 비진리 판명, 더 이상 진리라고 주장 X
- 아픈 것과 종기 : 근심, 마음의 상처(장막 성도들의 흠 → 세상 드러남)
- 장막 성도들 잘못 회개하지 않음
- 여섯째 대접 → 큰 강 유브라데 : 강물 마름, 왕들의 길 예비
: 심판의 말씀 → 강물(교리) : 비진리 드러남 ⇒ 멸망자의 교리 사라짐
하나님의 제사장(왕)이 될 자들 : 바벨론 ⇒ 증거장막 성전
증거의 말씀(길)
- 유브라데 : 멸망자들의 활동 본부
∴ 실상 : 청지기 교육원
- 귀신의 영들 : 천하 임금들 → 아마겟돈(영적 전쟁터)으로 모음
- 이유 : 하나님과의 전쟁을 위해
- 마지막 일곱째 대접 재앙 → 공기, 풍문과 언론 보도 : 배도자, 멸망자의 실체 전국에 알려짐
: 귀신의 나라 바벨론 → 세 갈래 갈라짐
섬과 산악(청지기 교육원 지부들)이 없어짐.
- 큰 우박의 재앙 : 진노의 말씀, 말씀을 가진 목자
- 새요한 → 배도자, 멸망자의 행위 증거 ⇒ 재앙이 심히 커서 사람들 : 하나님 훼방함
