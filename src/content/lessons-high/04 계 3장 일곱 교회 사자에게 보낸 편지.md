< 계 3장, 일곱 교회 사자에게 보낸 편지 >
[핵심]
- 예수님 : 대언자 → 일곱 교회 보내신 편지 / 핵심 : 예수님과 이긴자와의 약속
- 예수님 → 니골라당과 싸워 이기는 자 : 12가지 복
⇒ 계시록의 약속한 목자를 만나야 함

[서론]
- 제목 : 일곱 교회 사자에게 보낸 편지
- 본문의 핵심
① 일곱 사자가 처한 현실 = 니골라당과 하나된 것 책망
② 이들(니골라당)과 싸워 이기는 자에게 약속하신 복 주실 것
- 천국, 영생 소망하는 신앙인이라면 알아야 함
① 이기는 자에게 주시겠다고 약속하신 12가지 복의 내용
② 이 복(12가지 복)을 받는 이긴자

[본론]
- 예수님의 지시대로 편지를 보내는 새요한
- 계 1장 새요한 → 계 2, 3장 일곱 교회 사자에게 편지 보냄
계 2장 4개 교회, 계 3장 3개 교회
- 편지의 내용
① 네 본 것 : 예수님의 형체, 일곱 별 일곱 금 촛대
② 이제 있는 일 : 사단의 미혹 사건
③ 장차 될 일 : 이기는 그에게 주겠다 약속하신 계 2~3장 12가지 복
(가장 중요한 내용)
→ 계 3장 각 교회별 편지의 내용, 약속하신 복 알아보자

- 사데 교회의 사자에게 보낸 편지(계 3:1~6)
: 이기는 자 → 흰 옷 입음, 생명책 반드시 녹명시켜 주겠다는 약속의 말씀
- 흰 옷 : 영적 마음의 옷 = 성도들의 옳은 행실(계 19:8)
- 깨끗하고 흠이 없는 신앙 상징
∴ 흰 옷을 입는다
= 그 사람의 행실이 옳다고 하나님과 예수님께 인정을 받는 것
- 생명책 : 계시록 6번 언급(계 3:5, 계 13:8, 계 17:8, 계 20:12, 15, 계 21:27)
- 생명책 = 천국 호적, 하나님께서 함께하시는 이긴자가 이끄는 신천지 교회의 교적부
① 이름이 기록된 사람
② 없는 사람
③ 기록되었다가 도말된 사람
④ 흐려진 사람
⇒ 오직 생명책에 녹명된 자 : 천국에 갈 수 있음
= 새 언약을 지킨 사람들
- 오늘날 천국 소망하는 모든 신앙인 확인해 보아야 함
: 자신의 이름이 생명책(천국 호적)에 등록 되어 있는가
- 빌라델비아 교회 사자에게 보낸 편지(계 3:7~13)
: 이기는 자 → 하나님 성전 기둥 : 결코 다시 나가지 않음
- 기둥 : 중책을 맡은 자
이긴자 → 하나님 나라 건설
= 가장 중요한 책무를 맡은 중진
- 결코 다시 나가지 않음
: 사단과의 전쟁 배신, 배도하지 않고 하나님과의 언약 지키며
하나님 나라에서 나가는 일 없다는 것 알리는 말씀
* 역대 배도한 자들과 같이 배도하지 않음
- 하나님, 새 예루살렘, 예수님의 새 이름 기록
: 하나님, 예수님, 천국 → 이기는 자 함께하신다는 약속
- 라오디게아 교회 사자에게 보낸 편지(계 3:14~22)
: 이기는 자 → 예수님의 보좌에 함께 앉게 된다는 약속
- 보좌 : 하나님이 앉는 의자
예수님 → 이긴자 : 보좌 삼아 함께 역사

◈ 결론
- 천국과 영생을 소망하는 우리가 찾고 만나야 할 사람
= 하나님, 예수님, 영계 천국 → 계 2~3장 약속한 목자 이긴자
- 계 2~3장 약속된 이긴자에게 가는 것
= 하나님과 예수님께로 나아가는 길
성경의 약속대로 신앙 → 약속의 목자 이긴자 만나 하나님과 예수님께 인정받는 신앙하자
