< 계 5장, 일곱 인으로 봉한 책 >
[핵심]
- 요한이 본 하나님 오른손 일곱 인으로 봉한 책 = 계시록
- 이기신 예수님 : 책의 인 계 6, 8장에서 떼심
- 예수님의 피로 사서 하나님 나라와 제사장 창조될 것 새 노래로 알림
[서론]
- 제목 : 일곱 인으로 봉한 책
- 일곱 인으로 봉한 책은 무엇, 예수님의 피의 효력은 언제, 누구에게 나타나는가
[본론]
- 계 5:1~5
- 계 2~3장 편지 보낸 후 영계로 올라간 사도 요한
→ 영계 하나님의 보좌 앞 : 하나님 오른손 일곱 인으로 봉한 책 보게 됨
누가 기록, 누가 가지고 계시는가?
- 책 : 하나님 친히 기록, 오른 손 가지고 계신 책
= 비유로 감추어 둔 계시록
→ 이루어야 할 하나님의 비밀한 말씀 기록
- 요한이 크게 운 이유
: 책의 인봉 떼어지지 않음 → 하나님의 비밀 이루어지지 않음
⇒ 하나님의 소망, 인류의 구원 이루어지지 않기 때문
- 장로 중 하나가 예수님께서 이김 → 일곱 인 떼실 것 알려줌
① 인을 뗀다 : 예언을 이루어 실체를 나타내 보이는 것
- 예수님께서 인을 뗄 수 있는 이유
: 예수님 → 세상 주관자 마귀와 싸워 이김
⇒ 마귀의 정체, 비밀 다 알고 계셨기 때문(요 16:33, 엡 2:2)
- 계 5:6~8 예수님 일곱 인으로 봉한 책 취함
- 구약 계시
: 사 29장 구약 봉한 두루마리 책
→ 겔 3장 하나님 : 책을 열어 인자에게 먹여주심
→ 패역한 이스라엘에게 전하게 하심
∴ 초림 때 예수님 통하여 성취
- 신약 계시
: 오늘날 하나님 오른손 신약의 봉한 책
→ 예수님 : 취하심. 인을 떼어 열어 이루심(계 6, 8장)
→ 계 10장 펼쳐진 책 : 천사 → 이긴자 새요한 받아먹음
→ 새요한 : 백성, 나라, 방언, 임금(죄 가운데 있는 세상 모든 교회와 교인들)
다시 예언, 계시 말씀 전함
- 새요한에게 계시를 받는 종들 = 하나님의 말씀을 지키는 자들
∴ 실체 = 계시 말씀으로 추수되어 인 맞은 12지파(계 14, 7장)
- 계 5:9~14 예수님 : 책을 취하심 → 네 생물, 24장로들
: 족속, 방언, 백성, 나라 ⇒ 예수님의 피로 사서 나라와 제사장 삼아주신다 새 노래 부름
- 족속, 방언, 백성, 나라
= 죄 가운데 사로잡혀 있는 세상의 모든 교회와 교인들(계 13:7, 계 17:15)
- 이들을 예수님의 피로 산다
= 구원하신다는 것
- 모세 때 : 애굽에 사로잡힌 이스라엘 백성들
→ 어린 양의 피와 살로 구원하신 사건 빙자
- 초림 때 : 예수님의 피와 살인 계시 말씀 먹어야 구원(요 6:51~58)
유월절 양의 실체
- 새 언약 : 유월절 양식(예수님의 피와 살)
→ 아버지 나라에서 이루기까지 다시 먹지 않음(눅 22:14~20)
- 예수님의 피와 살, 언제 어디서 누가 먹고 구원받는가
- 12지파
계 5:9~10 예수님의 피 → 하나님의 나라와 제사장
계 7:14 144,000 인 친 후 → 예수님의 피로 옷을 씻은 흰 무리
- 2천 년 전 흘리신 예수님의 피
→ 계시록 성취 때 창조 : 하나님 나라의 제사장과 흰 무리 곧 12지파
예수님의 피의 효력 나타남
- 예수님의 피로 산 하나님의 나라와 제사장
= 계시 말씀을 소유한 새 목자들
∴ 실체
① 추수되어 인 맞은 새 나라 12지파 144,000명(계 14:1~5, 계 7장)
② 흰 무리 = 백성
◈ 결론
- 약 2천 년간 비유로 감추어 둔 봉한 책
= 하나님이 친히 기록하신 계시록의 말씀
- 봉한 책 일곱 인 떼어 열어 이루신 분 = 예수님
열린 책 받은 자 = 계 10장 새요한(한 사람)
- 예수님 피 흘리신 목적
: 계시록 성취 때 하나님의 나라와 제사장 창조, 흰 무리 구원하시기 위함
- 새요한을 통해 증거받는 계시 말씀
= 예수님의 피의 말씀
→ 하나님의 나라와 제사장이 될 수 있는 자격을 갖추어 구원받자
