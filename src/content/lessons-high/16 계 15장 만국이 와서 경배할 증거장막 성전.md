< 계 15장, 만국이 와서 경배할 증거장막 성전 >
[핵심]
- 계 15장 : 계 12장 용과 싸워 이긴자들
→ 하나님 보좌 앞 유리바다 가 : 모세의 노래 어린 양의 노래 부름
- 만국이 와서 경배할 곳 : 하나님과 예수님이 함께하시는 증거장막 성전 알린 말씀

[서론]
- 제목 : 만국이 와서 경배할 증거장막 성전
- 계 15장 계시록 성취 때 창조 → 약속한 성전 : 증거장막 성전 알려줌
= 만국이 와서 경배할 곳
* 온 세계 모든 신앙인들 반드시 알아야 함
- 증거장막 성전 : 언제, 누구, 어떻게 창조되는가
기성 전통 교회와는 어떠한 차이
[본론]
- 계 15:1 하늘과 다른 이적
- 하늘 : 계 13장, 12장 하늘 장막
- 다른 이적 : 일곱 천사 → 계 16장 일곱 대접 재앙
- 다른 이적이라고 한 이유
: 배도한 장막 선민 뿐 아니라 그들을 멸망시킨 멸망자에게도 쏟아 심판하기 때문
(계 13, 12장 이적과 다름)
- 하나님이 진노하신 이유 : 계 2~3장, 13장 배도자, 멸망자들이 행한 죄 때문
* 일곱 금 대접에 대해서는 계 15:6~7 설명
- 계 15:2 짐승, 우상, 이름의 수 / 이들을 이긴 자들은?
- 짐승, 우상, 이름의 수 : 계 13장에서 본 짐승 조직들
= 장막에 들어온 멸망자들
- 이긴자들 : 계 12장 용의 무리와 싸워 이긴자들
- 이긴자들이 서 있는 유리바다가 : 하나님의 보좌 앞
- 불이 섞인 유리 바다 : 보좌 앞 펼쳐진 성경
= 속 사람을 씻어 주는 하나님 말씀(계시 말씀)
- 계시록 성취 때 짐승의 실체 : 청지기 교육원 일곱 목자들
- 우상 : 666짐승 → 세운 거짓 목자
- 그 이름의 수 : 멸망자가 된 장막성전 출신 목자
배도한 솔로몬 같은 자 ‘뱀 씨’
- 이긴자들이 가진 하나님의 거문고, 모세, 어린 양의 노래는?
- 하나님의 거문고 : 하나님의 책, 성경
- 모세의 노래 : 구약 성경 말씀
어린 양의 노래 : 신약 성경 말씀
- 이 노래가 유리바다 가에서 나오는 이유
: 계 10장 하나님의 책 받아먹은 목자 있기 때문
- 유리바다 가에 열린 증거장막 성전 : 만국이 와서 경배할 곳
- 이유 : 계 2, 3장 약속 → 이긴자들이 있는 이곳
⇒ 하나님과 예수님 계심, 주의 의로우신 일 나타났기 때문
- 증거장막 성전은 언제 열리게 될까?
- 그 때 : 계 15:5 이 일 후
= 계 12장 이긴자들이 있고 난 후
- 증거장막 성전 : 이긴자들 → 창조된 성전
새요한 중심, 이긴자들 : 계시록 전장 성취 사건 증거하는 성전
- 계시록의 사건 : 증거장막 성전에서 그 실체를 알 수 있음
* ‘성전’인 이유 : 거룩하신 하나님 함께하시고 하나님의 보좌가 임해 있기 때문
∴ 증거장막 성전의 실체
: 대한민국 경기도 과천 1984년 3월 창조된 신천지예수교 증거장막성전 12지파
※ 증거장막성전 : 약 2천 년 전 예수님께서 미리 이름까지 지어 놓으신 약속한 성전
- 계 15:6~7 일곱 천사가 받은 일곱 금 대접
- 일곱 천사가 나오는 성전 : 증거장막 성전
- 하나님의 진노 담은 일곱 금 대접 : 계 12장 용의 무리와 싸워 이긴자들
- 이긴자들을 진노의 대접으로 삼으신 이유
: 이겼고, 사건의 현장에서 직접 보았기에 배도자, 멸망자 잘 알고 있음
- 계 16장 이긴자들 : 하나님의 진노의 대접 → 배도자, 멸망자 짐승 목자들 심판
- 계 15:8 일곱 대접 재앙 마치기까지 짐승 소속자들
→ 증거장막 성전 들어갈 수 없음
- 재앙을 다 받고 회개하는 자들
→ 증거장막 성전 나아와 하나님께 경배할 수 있음
[결론]
- 계 15장 : 계 12장 이긴자들 → 하나님 보좌 있는 유리바다 가에 모임
이긴자들 → 증거장막 성전 창조 알려주신 말씀
= 계시록 전장 성취 사건 증거
⇒ 하나님이 함께하시므로 만국 와서 경배
- 지상 모든 교회, 교단 명칭 : 사람이 자의적으로 만든 것 불과
증거장막 성전 : 예수님이 약속하신 성전의 명칭
하나님, 예수님 함께하시는 약속한 성전 찾아 구원에 이르자
