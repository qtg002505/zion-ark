[본론]
- 주 재림과 계시록 전장이 성취되는 일
: 계 1:9~20 길 예비 일곱 사자(일곱 별)와 일곱 금 촛대 장막 출현함으로 시작
- 초림 때 : 세례 요한 출현(길 예비 등불 역사)
→ 세례 요한의 전(澱) : 약속의 목자 예수님 출현
- 재림 때 : 예수님이 택하신 일곱 사자 출현(재림의 길 예비 등불 역사)
→ 일곱 사자의 전(殿), 일곱 금 촛대 장막 : 약속의 목자 새요한 출현
- 계시록 성취 때 가장 먼저 출현하는 존재는(계 1, 2, 3장)
- 예수님
- 일곱 별(사자)
- 사단 니골라당
- 요한(새요한) = 네 번째로 출현한 인물
요한 : 예수님께 택함 받고 계 2~3장 일곱 교회에 편지하라 지시받는 일

- 계시록 성취되는 오늘날 새요한이 실상 계시를 받게 되는 영적 밧모 섬은?
- 약 2천 년 전 예수님의 제자 요한
: 실제 ‘밧모 섬’에서 환상 계시 받아 기록
- 오늘날 새요한
: 계시록이 이루어지는 사건 현장 첫 장막 곧 장막성전
- 영적 밧모 섬의 실상
= 길 예비 일곱 사자가 있었던 대한민국 과천 소재 ‘장막성전’
- 나팔 소리 같은 큰 음성 = 예수님의 음성
“너 보는 것을 책에 써서 일곱 교회에 보내라.” 라고 하심
- 요한 이 본 인자 같은 이(계 1:13~16)
= 예수님(일곱 금 촛대 사이에 계심)
- “인자 같은 이”라고 한 이유
: 변화하신 신령체(성령체)의 모습이기 때문
(이 땅에 계실 때의 육체의 모습 X)
- 자신을 소개하시는 예수님(계 1:17)
- 예수님 → 엎드러져 죽은 자같이 된 요한 : 오른손을 얹으시고 자신을 소개
① 죽었다가 살아나신 분(계 1:18)
② 사망과 음부의 열쇠, 곧 지옥문을 여닫을 수 있는 지혜 가지신 분
- 요한에게 오른손을 얹은 것
: 예수님께서 직접 택하여 안수하시고 목자로 삼으셨다는 의미
∴ 계시록 성취 때 새요한
: 예수님께 안수 받고 택함 받은 이때
→ 예수님의 이름으로 보내신 대언의 사자로서의 사명 시작
- 예수님 → 요한 : 기록하라 하신 “네 본 것, 이제 있는 일, 장차 될 일”은?
- 요한이 ‘본 것’ = 예수님의 형체와 일곱 별과 일곱 금 촛대
- 이제 있는 일 = 계 2~3장의 사건(사단의 미혹)
- 장차 될 일 = 사단 니골라당과 싸워 이기면
계 2~3장에 약속한 모든 복을 받게 되는 것
- 일곱 사자에게 보낸 계 2~3장의 편지
= 신령체(성령체) 예수님 지시에 따라 요한이 자기가 본 것 책에 써서 보내게 됨

- 계 1:20 일곱 사자 = 일곱 별로 비유하신 이유는?
: 별이 하늘에 있듯, 그들이 역사한 장막 = 하늘로 비유했기 때문
- 일곱 별과 일곱 금 촛대 = 비밀이라 하신 이유는?
: 계시록에 예언된 ‘배도한 장막과 목자’임을
세상 목자도, 일곱 사자 자신들도 모르기 때문
- 실상
① 일곱 사자와 장막성전(재림의 길 예비 등불 역사)
: 1966년 대한민국 경기도 과천 청계산 아래 출현
② 새요한이 예수님께 택함 받고 지시받은 때
: 1977년 가을

◈ 결론

- 성령체 예수님 → 새요한 : 택함
① 일곱 별과 일곱 금 촛대의 실체를 보고
② 편지하라 지시 받은 일 알려주신 말씀

예수님께서 택하신 약속의 목자를 만나, 계시록의 실체를 증거받고 구원에 이르기를 바람
