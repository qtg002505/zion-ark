< 계 4장, 영계 하나님의 보좌와 계열 >
[핵심]
- 요한 : 계 2~3장 편지 보낸 후 → 영계 하나님의 보좌에 올라감(성령의 감동)
① 본 것 : 이후에 마땅히 될 일, 영계 하나님의 보좌와 계열
② 들은 것 : 하나님, 영계 나라 → 장차 이 땅에 임해 오실 것 들음
[서론]
- 제목 : 영계 하나님의 보좌와 계열
- 영계 하나님의 보좌 앞 올라간 새요한
① 본 것 : 이후에 마땅히 될 일, 영계 하나님의 보좌와 계열
② 들은 것 : 하나님, 영계 나라 → 장차 이 땅에 임해 오실 것 들음
하나님과 영계 천국은 언제, 어디에, 누구에게 오시는가
[본론]
- 계 4:1 ‘이 일 후에 내가 보니’
- 이 일 후 : 계 2~3장 편지를 보낸 후
- 본 자 : 약속한 목자 새요한
계시록 사건이 이루어질 때 곁에서 보고 들은 한 사람
- 새요한이 보고 들은 것
① 본 것 : 하늘의 열린 문 영계 천국, 계 21장 거룩한 성 새 예루살렘의 문
② 들은 것 : 이후에 마땅히 될 일, 계 4장 ~ 22장에 기록된 사건(예수님의 음성)
- 계 4:2~3 요한 : 성령 감동(영 → 하늘 영계) → 하나님의 보좌와 계열들 봄
- 시대별 하늘에 올라갔다 온 자
① 초림 때 : 예수님(요 3:13)
② 주 재림 때(계시록 성취 때) : 새요한
- 증거 : 하늘에서 보고 들은 것 증거
- 보좌에 앉으신 이 = 하나님
① 벽옥과 홍보석 같다 : 푸른 하늘, 붉은 땅의 모습 빙자 비유
= 천지 창조주 하나님
② 보좌에 둘려 있는 무지개 : 언약 상징(창 9:13)
③ 녹보석 같다 = 하나님 언약 영원함

- 계 4:4~5 24장로들 : 흰 옷, 금 면류관 쓰고 있음
- 24장로 : 하나님 나라 모든 일 맡은 24영
행정 담당 문관과 같은 역할
- 보좌로부터 번개, 음성, 뇌성이 남
① 번개 : 영들이 빠르게 활동하는 모습
② 음성, 뇌성 : 하나님의 정사하는 소리
→ 하늘의 영들 : 계시록을 이루기 위해 분주한 모습
- 보좌 앞 일곱 등불 켠 것 = 하나님의 일곱 영
= 하나님의 말씀 대언 일곱 사자
- 일곱 등불, 눈이라고 한 이유 = 교육, 감찰의 사명
- 계 4:6~11 보좌 앞 수정과 같은 유리바다
보좌 가운데, 주위 네 생물
- 보좌 앞 유리바다 : 속사람을 씻어 주는 하나님의 말씀
= 보좌 앞 열린 책의 말씀
- 네 생물 : 네 천사장
전쟁, 심판 주관, 무관과 같은 역할
- 앞 뒤에 가득한 눈 : 천천만만의 천사들
- 네 생물의 역할에 따른 모양
① 사자 : 짐승 같은 자 심판
② 송아지 : 사람의 마음 밭 갈고 가라지 뽑는 심판
③ 사람 : 지각 → 참, 거짓 심판
④ 독수리 : 영 심판
- 네 생물 각각 여섯 날개
날개 = 돕는 역할, 네 천사장들을 돕는 여섯 장로들 = 24장로
- 네 생물, 24장로들 항상 함께함

- 하나님과 천국은 언제 어디에 장차 오시는가?
- 오시는 때 : 계시록 성취 때
- 오시는 곳 : 계 21장 하나님, 거룩한 성 새 예루살렘
↓ 임함
새 하늘 새 땅
- 새 하늘 새 땅 : 사단 니골라당과 싸워 이긴자가 있는 곳(계 3:12, 21)
이긴자를 통해 창조된 인 맞은 144,000과
예수님의 피로 죄 사함 받은 흰 무리가 있는
새 나라 새 민족 신천지 12지파(계 7장)
- 요한에게 영계 천국을 보여주신 이유
: 이 땅에 하나님께서 임해 오실 하나님의 나라를
보고 들은 대로 창조하게 하기 위함
- 실상 : 1995년 3월 14일 수원 공설운동장 신천지 12지파 보좌 구성
(영계 하나님 보좌 계열대로)

◈ 결론
- 계 4장, 예수님 → 새요한 : 영계 하나님의 보좌와 계열 보여주신 이유
= 이 땅에 하나님께서 임해 오실 하나님의 나라를 창조하기 위함
∴ 신천지 12지파(조직, 명칭, 교명, 인명도 계시록대로 도장찍은 것 같이 창조됨)
- 신천지 12지파 보좌 구성
이긴자를 중심, 24부장, 7교육장, 네 생물과 같은 자문, 장년, 부녀, 청년회
네 그룹의 조직, 12문과 같은 12지파장들
- 보좌 앞 수정 같이 맑은 계시 말씀이 있다는 것
: 하나님의 보좌 → 우리 속사람을 깨끗이 씻어 주는 하나님의 말씀이 나온다는 것
새요한을 통해 증거되는 계시 말씀 → 속사람 씻어 천국을 상속받자
