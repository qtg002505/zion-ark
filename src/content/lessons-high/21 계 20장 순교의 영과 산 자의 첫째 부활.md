< 계 20장, 순교의 영과 산 자의 첫째 부활 >
[핵심]
- 계 20장 : 계 19장 어린양 혼인 잔치 청함 받은 영, 육 하나됨
: 첫째 부활 참예, 천 년 동안 왕 노릇
천 년 후 마지막 심판 내용
[서론]
- 제목 : 순교의 영과 산 자의 첫째 부활
- 첫째 부활 : 언제 있는 일, 첫째 부활 참예하는 자들, 천 년 후 있게 되는 일
[본론]
- 계 20장 천 년 안/후의 사건 나누어짐
- 천 년 안 : 용 → 무저갱 갇히는 내용, 영육이 하나되는 첫째 부활
- 천 년 후 : 곡, 마곡의 심판, 육이 죽은 자들의 영 → 심판 받는 내용
- 계 20:1~3 만국 미혹 용 잡음 → 무저갱 던져 잠그고 나오지 못하도록 인봉
- 용 : 마귀, 사단 상징 곧 악령
- 용을 잡는 쇠사슬 : 증거의 말씀(계 12:11)(악령을 잡는 것 육적 쇠사슬 X)
용의 정체 → 성경으로 증거하여 잡을 수 있음
- 무저갱 : 음부, 지옥
- 무저갱 열쇠 : 사단의 비밀을 아는 지혜(비유한 열쇠 = 지혜)
- 인봉했다 : 더 이상 용이 나오지 못하도록 막는 것
- 계 20:4~6 보좌에 앉아 심판하는 자들
마 19:28 심판하는 자들 : 예수님의 12제자들, 영적 새 이스라엘 12지파장들
계 4장 하나님 보좌 계열에 앉은 영육 모든 자들
- 심판의 도구 : 말씀

- 계 20장 첫째 부활
- 첫째 부활 : 계시록 성취 때 짐승의 표 받지 않고 이기고 살아남은 자들
→ 순교한 영 덧입어 하나가 되는 것(고전 15:51~54)
- 짐승 : 장막성전 삼킨 일곱 목자들
- 우상 : 거짓 선지자, 장막 전도사 출신 목자 17명
- 짐승의 표 666 : 사단의 비진리, 솔로몬 같은 거짓 목자
- 짐승의 표를 받지않고 살아남은 자
: 계 8, 9장 영이 죽임을 당하지 않은 사람들
계 12, 13장 짐승, 우상, 이름의 수 이기고 벗어난 이긴자들
⇒ 범죄 이전 하나님의 모양, 형상 입게 되는 첫째 부활자들
- 계 20:7~15 천 년 후의 사건
: 곡과 마곡 심판받는 일,
육이 죽은 영들 → 하나님의 심판대 앞에서 심판 받아 영생, 영벌로 나누어지는 내용
- 용이 미혹하는 곡과 마곡 : 천년성 밖에 있는 자들
하나님 소속 아닌 자들(계 22:15) ⇒ 불로써 소멸 받게 됨
- 천년성 안에 있는 자들
: 더 이상 미혹, 함락되지 X, 육이 죽지 않고 세세토록 주와 함께 살게 됨
- 이유 : 사단 → 언제 옥에서 나오는지 알고 있기 때문
- 천 년 후 흰 보좌 위 앉아 심판하는 자 : 하나님
- 죽은 자들 : 창세로부터 육이 죽은 영들
- 심판하는 책들 : 천국 법전 성경 66권
[결론]
- 천년 세계 : 성 안과 밖, 첫째 부활
- 첫째 부활 : 계 19장 혼인 잔치 집 영육 손님들 청한 후 있게 됨
- 순교한 영들, 하나님의 인 맞은 자들 하나 됨
→ 그리스도 더불어 천 년 동안 왕 노릇 하는 것
- 천 년 후 : 곡, 마곡에 대한 심판, 육이 죽은 자들의 영의 심판
→ 성경 기록된 약속 깨달아 믿음 ⇒ 첫째 부활자
→ 신앙의 목적 : 천국, 영생 소망 들어가자
