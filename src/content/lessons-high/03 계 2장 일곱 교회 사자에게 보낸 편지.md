< 계 2장, 일곱 교회 사자에게 보낸 편지 >
[핵심]
- 예수님 : 대언자 → 일곱 교회 보내신 편지 / 핵심 : 예수님과 이긴자와의 약속
- 예수님 → 니골라당과 싸워 이기는 자 : 12가지 복
⇒ 계시록의 약속한 목자를 만나야 함

[서론]
- 제목 : 일곱 교회 사자에게 보낸 편지
- 본문의 핵심
① 일곱 사자가 처한 현실 = 니골라당과 하나된 것 책망
② 이들(니골라당)과 싸워 이기는 자에게 약속하신 복 주실 것
- 천국, 영생 소망하는 신앙인이라면 알아야 함
① 이기는 자에게 주시겠다고 약속하신 12가지 복의 내용
② 이 복(12가지 복)을 받는 이긴자

[본론]
- 예수님의 지시대로 편지를 보내는 새요한
- 계 1장 새요한 → 계 2, 3장 일곱 교회 사자에게 편지 보냄
계 2장 4개 교회, 계 3장 3개 교회
- 편지 서두 : 수신자, 발신자 기록,
‘가라사대’ 표현 : 대언자 있음
- 세 존재 출현 : 일곱 사자, 니골라당, 약속의 목자 새요한
오늘날 예수님께 택함 받음
- 편지 실상의 사건
① 편지 보내라 지시하는 실상의 사건
: 1977년 가을 대한민국 경상북도 청도 현리교 부근에서 성취
② 일곱 사자에게 편지를 보낸 것 : 1979년

- 편지의 내용
① 네 본 것 : 예수님의 형체, 일곱 별 일곱 금 촛대
② 이제 있는 일 : 사단의 미혹 사건
③ 장차 될 일 : 이기는 그에게 주겠다 약속하신 계 2~3장 12가지 복
(가장 중요한 내용)
⇒ 각 교회별 편지의 내용과 약속한 복 알아보자
- 에베소 교회의 사자에게 보낸 편지(계 2:1~7)
: 니골라당과 싸워 이기는 자 → 낙원 생명나무 과실
- 낙원 : 하나님께서 계신 영계 천국(셋째 하늘, 고후 12:1~4)
= 거룩한 성 새 예루살렘(계 22장)
- 영계 천국(거룩한 성 새 예루살렘) 장차 새 하늘 새 땅 내려올 때(계 21장)
→ 그 곳(새 하늘 새 땅) : 하나님의 낙원이 됨
- 생명나무의 실체 : 하나님의 말씀을 가진 자
- 본문(계 2장) 생명나무 = 예수님
예수님의 입에서 나오는 생명의 말씀 = 생명나무 과실
- 서머나 교회의 사자에게 보낸 편지(계 2:8~11)
: 니골라당과 싸워 이기는 자 → 생명의 면류관, 둘째 사망의 해 면함
- 생명의 면류관 = 영생
- 둘째 사망 = 육신이 죽은 후 그 영혼이 받게 될 지옥 형벌
- 첫째 사망 : 육신의 죽음
∴ 둘째 사망의 해 면함
= 육신이 죽은 후 그 영이 받게 될 지옥 형벌 면하게 해주겠다
- 둘째 사망의 해 면하지 못한 모든 자들 : 하나님의 말씀으로 심판(계 20장)
심판을 받지 않으려면 → 대적과 싸워 이김 : 둘째 사망의 해 면함의 복 받음
- 버가모 교회의 사자에게 보낸 편지(계 2:12~17)
: 두 가지 복(감추었던 만나, 흰 돌) 약속
- 감추었던 만나 : 비유로 감추어져 있던 천국 비밀의 말씀
= 계시 말씀
- 흰 돌 : 심판
- 돌 : 단단한 성질, 부딪힌 것이 부서짐
∴ 흰 돌을 주시겠다
= 하나님의 말씀으로 심판하는 심판권을 주시겠다는 것
- 두아디라 교회의 사자에게 보낸 편지(계 2:18~29)
: 이기는 자에게 만국을 다스리는 철장 권세, 새벽별 주시겠다는 약속
- 철장 : 다스리는 권세, 치리권
= 생명의 말씀으로 만국을 다스리는 권세 주시겠다는 약속
- 새벽별 = 예수님(계 22:16)
∴ 새벽별을 주신다는 것
= 영이신 예수님 → 이긴자 새요한과 함께 하시겠다는 약속의 말씀

◈ 결론
- 천국과 영생을 소망하는 우리가 찾고 만나야 할 사람
= 계 2~3장 약속한 목자 이긴자
- 이유 : 우리가 소망하는 12가지 복
→ 니골라당과 싸워 이긴 이긴자에게 주시기 때문
- 우리 : 계 2~3장 약속된 약속의 목자 이긴자 만나
① 12가지 복
② 영생의 양식 받음 ⇒ 소망하는 천국, 영생 이르자
