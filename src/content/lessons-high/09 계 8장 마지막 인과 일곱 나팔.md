→ 그들이 처한 상황, 나팔처럼 외쳐서 알리고 깨우치는 내용
- 본 장 : 4개 나팔 불림
[서론]
- 제목 : 마지막 인과 일곱 나팔
- 계 8장에 대한 다양한 해석
오늘날 기독교 목회자들 : 핵전쟁, 소행성 충돌 등
사 8:20 증거하는 말 : 성경과 맞지 X → 아침 빛 보지 못함
계 22:18~19 계시록 가감 → 재앙, 천국 못 들어감
⇒ 계 8장 참 뜻 알아보자
[본론]
- 마지막 인
- 계 5장 : 일곱 인 봉한 책 계시록
→ 계 6장 여섯 개 인 떼어짐 → 계 8:1 마지막 일곱째 인 떼어짐
- 봉함 : 비유로 예언된 상태(실체 출현 전)
마지막 인 떼어짐 → 하나님의 봉한 책
: 열려서 보임 ⇒ 기록된 예언 이루어져 실체들 출현
- 계 8:2 일곱째 인 뗄 때, 하나님 앞 시위한 일곱 천사 : 일곱 나팔 받음
일곱 천사 → 일곱 나팔 불어 일곱째 인 뗀 후 일어난 사실 알림
- 나팔
- 나팔 : 하나님의 말씀 증거하는 사람(사 58:1)
계 6:6 밀 한 되, 보리 석 되 : 믿음의 씨로 빼낸 성도들
→ 나팔 삼아 증거
- 계시록에서 알아야 할 것
: 일이 이루어질 때
→ 예수님 → 택함 받음 : 실체 보고 듣고 증거하는 한 사람 있음
- 계 8장 : 1~4째 나팔까지 불림
나팔 소리 : 배도 → 이방으로 쫓겨난 선민이 당하는 재앙 알리는 소리
- 계 8:3~5 성도들의 기도 상달 = 금 향로 : 향 → 향연 올라감
- 금 향로 : 변치 않는 진리의 말씀을 가진 사람
- 향 : 성도들의 기도
- 향연 올라가는 것 : 기도가 상달되는 것
- 천사, 향로 : 단 위의 불 → 땅 쏟게 된다
= 약속의 목자 → 말씀의 불 쏟아 심판 : 육체로 돌아간 장막 성도
일곱 나팔 중 8장에서 불리는 4개의 나팔의 재앙에 대해 알아보자
- 계 8:7 일곱 천사 : 나팔 불기 시작
- 첫째 천사 : 나팔
피 섞인 우박, 불 → 땅 : 땅 1/3, 수목 1/3 사윔
① 우박 : 하나님의 진노의 말씀, 말씀을 받은 목자
② 땅, 수목, 풀 : 배도한 장막성전의 성도들(사 40:7)
∴ 첫째 나팔의 재앙
= 배도한 선민 : 우박, 불 같은 하나님의 진노의 말씀으로 심판 받은 것
- 둘째 천사 : 나팔 / 불붙는 큰 산과 같은 것
→ 바다 : 바다 1/3 피, 피조물, 배들 1/3 죽고 깨어짐
- 불붙는 큰 산
: 배도함 → 말씀으로 심판 받은 장막성전의 본부 교회
- 장막성전 → 바다, 즉 세상(단 7:3, 17) 버려짐
배도한 선민의 영 → 피 곧 세상 교리 빠져 죽음
‘배’로 비유 → 그들의 지교회 ⇒ 세상에 속하여 무너지게 되었음 알림
- 실상
장막성전 : 전국 약 80여 개 지교회,
이 말씀 응할 때 → 세상의 비진리 조직 하나되어 모두 없어짐
- 셋째 천사 : 나팔 / 쑥 별 : 하늘 → 강들, 샘 떨어짐
⇒ 물 1/3 쑥, 물 마신 사람들 : 죽음
- 쑥 별 : 거짓 목자
하늘에서 떨어졌다 : 계 13:6 하늘 곧 장막성전 → 멸망자 하나됨
- 셋째 나팔 소리 : 거짓 목자, 쑥과 같은 거짓 교리
→ 전도자들(강 비유) 넣어줌
⇒ 선민의 영들 : 받아먹고 죽게 되는 것 알리는 말씀

- 넷째 천사 : 나팔 / 해, 달, 별 → 침을 받음 : 1/3 어두워지고 낮, 밤 1/3 빛을 잃음
- 해, 달, 별 : 선민 장막의 목자와 전도자와 성도
- 장막에 들어온 이방 교권자들
→ 침해 받아 진리의 빛 비추지 X ⇒ 점점 심령 어두워짐
- 공중 날아가는 독수리 → 땅에 거하는 자들 : 화, 화, 화가 있을 것 외침
- 독수리 : 네 생물 중 하나, 천사장
→ 땅에 거하는 일곱 금 촛대 장막 성도들
: 나팔 재앙 세 개 남은 것 알리는 말씀
◈ 결론
- 일곱 나팔의 재앙
: 계 2~3장 예수님의 편지 받고도 회개하지 X,
→ 이방 소굴 들어간 일곱 금 촛대 장막에 내리는 형벌 알리는 소리
- 안일하지 말자
요한계시록 성취되는 오늘날,
나팔 소리를 듣고도 회개 X 배도자들처럼
자신의 신앙을 돌아보지 않는 안일한 신앙인 X,
보고 들은 증인 : 약속의 목자 → 계시록 이루어진 실상 듣고 확인
⇒ 구원 이르는 참 신앙인 되자.
