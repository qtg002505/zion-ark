< 계 9장, 무저갱의 황충과 범죄한 천사 >
[핵심]
- 계 8장 : 1~4째 나팔까지 불림,
계 9장 : 5~6째 나팔 불림
- 나팔 내용 : 이방으로 쫓겨난 배도한 선민의 영
→ 1/3씩 죽임 당하는 것 알리는 소리
[서론]
- 제목 : 무저갱의 황충과 범죄한 천사
- 계 8장 → 계 9장 : 5~6번째 나팔 불릴 때 나타나는 사건
무저갱 황충과 유브라데 결박한 네 천사
→ 사람들 : 고통, 죽게 되는 내용
- 계 9장 성취 때의 사건 참 뜻과 실상
- 신앙인 : 어떻게 해야 구원 받을 수 있는가 알아야 함
[본론]
- 계시록에서 불리는 일곱 나팔
- 나팔 = 대언의 육체(사 58:1)
- 계 8~9장 나팔의 실체 : 믿음의 씨로 뺴낸 성도들(계 3:4,계 6:6)
- 나팔 소리
: 계 6장에서 쫓겨난 배도한 선민 → 이방 속하여 1/3 영적 죽임 당하는 것 알리는 소리
- 나팔을 부는 이유 : 배도한 선민에게 죄와 허물이 있음을 알려 회개케 하기 위함
- 나팔이 불리는 시점
① 계 6장 선민 배도 → 심판 : 이방에게 쫓겨남
② 봉함된 일곱 인 다 떨어진 후
- 나팔이 불리는 장소
: 계 6장 배도 → 심판 : 이방 소속 일곱 별 일곱 금 촛대 장막

- 다섯 번째 나팔의 사건
- 계 9:1~3 하늘에서 떨어진 별
: 장막성전 출신 당을 지어 멸망자와 하나된 자
- 실상 : ‘뱀 씨(가명)’
- 무저갱 : 멸망자들의 활동 본부
- 실상 : 청지기 교육원
- 무저갱의 열쇠
: 황충인 멸망자 곧 청지기 교육원의 일곱 목자를
뱀 씨(가명)가 장막성전으로 끌어들인 지혜
- 황충과 같은 멸망자인 일곱 목자들
- 계 9:4~11 하나님의 인 맞지 아니한 사람들
곧 배도한 장막성전 성도들
→ 이방 교단 교인으로 만드는 과정 : 다섯 달 동안 괴롭게 함
* 영적으로 노아 때와 같은 상황(창 7:24, 마 24:37)
- 죽고 싶어도 죽음이 피해 감
: 그들이 지은 죄에 대한 벌
3) 황충들의 임금 : 음녀
※ 실상 : 청지기 교육원 목자 ‘땅 씨(가명)’
- 여섯 번째 나팔의 사건
- 계 9:12~16 결박한 네 천사
= 범죄한 천사(유 1:6, 벧후 2:4)
- 결박한 천사가 있는 큰 강 유브라데 : 지옥
- 범죄한 천사 → 년, 월, 일, 시 사람 1/3 죽이기로 예비
- 실상 : 1981년 9월 20일 14시 목사 임직식(계 13:16~18)
- 범죄한 천사들 소속 이만만 마병대
- 계 9:17~19 말과 탄 자들 = 사단 소속 영, 육
- 말의 입 → 불, 연기, 유황 → 배도한 장막 성도 1/3 영 죽임
- 불빛, 자줏빛, 유황빛 흉갑 : 각색 거짓 교리 곧 주석
- 말들의 꼬리에 머리
① 꼬리 : 거짓 목자
- 실상 : 안수 한 번 → 이방 목자가 된 장막성전 출신 17명 전도사
② 머리 : 그들에게 안수한 멸망자 곧 청지기 교육원 일곱 목자
- 이러한 재앙 → 회개치 X 자들 = 배도한 장막성전 성도들
계 9:20~21 멸망자인 거짓 목자를 섬기며 악령에게 경배하게 됨
[결론]
- 5~6째 나팔 불림
사단 소속 멸망자들 → 배도한 하늘 장막(장막성전 성도들의 영)
: 비진리 → 괴롭게하고 죽이는 일
- 배도한 선민 : 회개 X, 악령과 거짓 목자에게 경배
- 계시록 성취 실상의 말씀 나팔 불어 알리는 소리를 들을 때
→ 회개, 구원의 처소 찾아 천국과 영생에 이르자
