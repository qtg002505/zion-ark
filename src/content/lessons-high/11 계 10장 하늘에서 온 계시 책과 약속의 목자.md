< 계 10장, 하늘에서 온 계시 책과 약속의 목자 >
[핵심]
- 계시록 성취 때, 열린 계시 말씀을 받은 약속의 목자
: 예수님께서 인을 떼어 다 이루실 때 옆에서 한 장 한 장 다 보고 들은 새요한
- 만민 : 약속의 목자 통해서만 → 신약 계시 증거 받을 수 있음
[서론]
- 제목 : 하늘에서 온 계시 책과 약속의 목자
- 계시 책 받아먹은 목자
- 초림 때
하늘에서 온 계시 책을 받아 먹은 약속의 목자 : 예수님
하나님 사 29장 봉한 책 → 겔 2:10 펼치시고(여시고)
→ 인자 예수님 : 겔 3장, 열린 책 받아먹고
⇒ 패역한 이스라엘 백성에게 전함(마 15:24)
- 오늘날
계 5장 일곱 인으로 봉한 책 계시록 : 천상천하 누구도 뜻 알 수 없었음
이기신 예수님 → 계 6, 8장 책의 인 떼어 열어 이루심
천사 → 계 10장 열린 책 : 요한 먹여줌
→ 계 22:16 교회들에게 증거 ⇒ 비로소 계시 말씀 만방에 전해짐
∴ 본 장 → 하늘에서 계시 책을 받아먹은 신약의 약속의 목자, 그의 사명 알아보자
[본론]
- 계 10:1~4 힘센 다른 천사 : 하늘에서 열린 책 가지고 옴
- 천사 : 구름을 입고 머리 위 무지개, 얼굴 : 해, 발 : 불기둥 같음
: 계 1장 예수님과 같은 모습 = 예수님의 약속대로 왔다는 것
- 천사의 손에 펴 놓인 작은 책 : 열린 계시록의 말씀
하나님 : 직접 쓰시고 인봉 → 오른손 가지고 계심 ⇒ 예수님
예수님 : 책 펼쳐서 이루시고 천사에게 지시 ⇒ 새요한에게 전달하게 하신 것
- 천사 : 땅, 바다 밟고 큰 소리 외치는 것 → 요한에게 보여줌
: 열린 말씀 → 땅과 같은 배도자, 바다 같은 멸망자 심판하라고 보여준 것
- 요한(새요한) : 보여준대로 배도자, 멸망자 말씀으로 심판

- 계 10:5~7 땅, 바다 밟고 있는 천사 : 오른손 들고 지체하지 않겠다고 창조주께 맹세
- 지체하지 않겠다는 것 : 심판과 일곱째 나팔의 비밀 속히 이루겠다는 것
- 일곱째 나팔의 비밀
계 10:7 일곱째 천사 나팔 불 때 → 하나님의 비밀 이루어짐
(그 종 선지자들에게 전하신 복음과 같이)
계 11:15 일곱 째 나팔 소리 : 세상 나라 → 하나님 나라
고전 15:51~54 부활과 영생 이루어짐
∴ 하나님의 비밀
- 모든 인류 : 천국에서 영생하려면
① 일곱째 나팔 소리 들어야 함
② 일곱째 나팔의 실체인 신약의 약속의 목자 만나야 함
- 계 10:8~10 하늘에서 열린 책 갖다 먹으라는 음성
→ 요한 : 열린 계시 책 받아먹음
- 열린 계시 책 받아먹은 이 : 약속의 목자 새요한
- 열린 책을 먹었다 : 말씀을 모두 깨달아 마음에 새김 → 소화가 되었다는 것
새요한의 영 : 영적 책(말씀)을 받아 먹었다는 것
= 계시록 완전히 통달했다는 것
∴ 새요한 : 걸어다니는 성경
- 책을 먹으니
① ‘입에서는 꿀같이 달다’
: 비밀의 말씀을 깨달아 기쁨
② ‘배에서는 쓰게 되더라’
: 깨달은 후에 전할 생각을 하니 겪을 고난이 많아 심히 괴롭다는 것
- 계 10:11 새요한 → 백성, 나라, 방언, 임금 : 다시 예언하라
= 죄 가운데 있는 모든 교회들에게 다시 전하라는 말씀
- 다시 전하라고 하신 이유
: 지금까지 그들이 사람의 계명으로만 배웠고 만국이 음행의 포도주로 무너져 있기 때문

- 계 10장 성취 때, 열린 계시 책은 어디에 가있을까
누구를 만나야 우리도 먹을 수 있을까?
- 책은 어디에
하나님 손 봉한 책 → 예수님 주었음(하나님에게 없음)
예수님 → 천사 주었음(예수님에게도 없음)
천사 → 계 10장 새요한 전달(천사에게도 없음)
∴ 책 : 새요한의 배 속에 있음
- 모든 만민 → 약속의 목자 새요한에게 와야만
① 계시 말씀 증거받고 ② 천국에 이를 수 있음
[결론]
- 계 10장 : 예수님께서 신약의 약속한 목자를 알리는 내용
- 약속하신 계시의 전달 과정대로 계 10장 같이 열린 책 받아먹은 목자
- 계 22:8, 16 예수님이 보낸 사자
- 계시록 전장의 실체를 보고 듣고 증거하는 유일한 약속한 목자
- 만민 : 계 10장 천사 → 펴 놓인 작은 책 곧 열린 계시록 받아먹고
계시록과 신, 구약을 통달한 신약의 약속의 목자를 만나서
계시록이 이룬 실상 증거받아 천국, 영생 이르시는 성도님이 되자
