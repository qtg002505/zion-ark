[서론]
- 제목 : 처음 익은 열매 시온산 십사만 사천
- 계 14장 : 계 13장과 비교되는 장
- 계 13장 : 길 예비 장막성전 → 짐승에게 표 받고 배도한 사건 알린 것
- 계 14장 : 시온산 : 하나님의 말씀 → 인 맞은 144,000 알리는 사건
- 장소와 인물
- 장소 : 주 재림 때 하나님과 예수님이 계시는 시온산
- 누구 : 시온산 → 추수, 인 맞은 처음 익은 열매 144,000
[본론]
- 계 14:1~5 시온산 : 어린 양, 인 맞은 144,000
- 시온 : 예수님(사 60:14 사람 = 시온)
- 시온산 : 시온(예수님)이 함께하시는 영적 산
- 선민의 조직체( = 영계 천국 보좌 임하는 이 땅의 천국)
∴ 시온산 실체 : 예수님 중심으로 한 사람들 모인 조직체
= 영적 새 이스라엘 12지파
- 하나님, 예수님 이름 → 인 맞은 144,000명
: 진리 말씀 추수 → 처음 익은 열매들
① 인(印) : 하나님의 말씀, 말씀을 받은 목자 새요한
② 인을 친다는 것 : 하나님의 말씀 → 마음에 새겨 준다는 의미(히 8:10~13)
- 새요한의 증거 인정하는 자들 → 인 맞은 자
⇒ 하나님, 예수님의 소유 곧 천국 백성

- 144,000이 부르는 새 노래
새 노래 : 계시록 성취 실상의 복음
영원한 복음 → 나라, 족속, 방언, 백성에게 증거됨
= 시온산 144,000명 밖에 배울 자 X
= 시온산과 144,000명을 확인해 주는 증거
- 계 14:9~12 짐승의 표 받은 자들 심판 받음
- 짐승 : 하늘 장막 삼킨 멸망자
- 짐승이 세운 우상 : 멸망자들이 세운 거짓 목자들
- 짐승의 표 받은 자들 : 계 13장 배도한 하늘 장막 성도들
하나님의 진노의 포도주(심판의 말씀) → 심판 : 불, 유황 못
⇒ 세세토록 고난 받게됨
- 하나님의 계명과 예수 믿음 지키는 자들
: 계 15:2 짐승, 우상, 이름의 수 이기고 벗어난 자들
진리의 말씀 → 거듭나 추수된 처음 익은 열매 144,000
- 계 14:14~16 구름 위 앉은 천사 : 낫 → 곡식 거둠
: 추수하는 일 있음 말하는 것
- 추수하는 과정
① 하나님 : 렘 31장 두 가지 씨 뿌릴 것 예언
② 마 13장 초림 예수님 → 예수님의 밭(교회) : 하나님의 씨 뿌리심
마귀 : 그 밭에 가라지 덧뿌림
③ 마 24:29~31, 계 14장 예수님 : 추수하러 다시 오실 것 약속
추수 때 : 세상 끝(주 재림 때)
→ 하나님의 씨, 마귀 씨로 난 자들 구분됨
- 추수한 알곡
: 하나님의 씨 → 천국의 아들들
영적 바벨론 → 시온산 증거장막성전
→ 추수, 인, 처음 익은 열매 144,000
- 추수 때 성도 : 추수꾼 말 들어야 함
추수꾼의 인도 → 영적 곳간
: 시온산 증거장막성전 추수되어 감
구원, 영생 얻을 수 있음

- 추수되지 못한 가라지
: 지옥의 아들들 → 단 묶여 지옥 불 심판 당함(마 13:37~39)
- 단으로 묶는 자와 묶는 줄
단으로 묶는 자 : 교인들이 추수되지 못하도록 막는 자기 교회 목자
묶는 줄 : 거짓 목자의 말(비진리)
- 계 14:17~20 천사 → 낫 : 땅의 포도송이 ⇒ 포도주 틀 던져버림
- 포도송이 : 계 13장 하늘 장막 성도들(멸망자들의 소굴로 쫓겨남)
→ 하나님 말씀 심판 받게 됨
- 성 밖 : 틀 밟힘 → 피가 남 ⇒ 말굴레까지 닿고 1,600스다디온에 퍼짐
: 배도한 장막성전의 멸망 소식
→ 목자(말)의 입 ⇒ 약 750리(300km) 전국 퍼지게 된 것
[결론]
- 추수 때 : 목자, 성도들 → 천국 곳간 시온산으로 추수되어 가야함
- 추수되어 가지 않고 밭에 남아 있는 것 : 가라지라는 증거
- 신천지예수교 증거장막성전 시온기독교선교센터
: 새 노래 계시 말씀 인 침, 추수
- 추수 → 천국 곳간 들어가는 것 : 천국 가는 것
∴ 실체 : 시온산 처음 익은 열매(약 1:18) 144,000명
144,000 인친 후 → 큰 환난 : 예수님의 피 희게 된 무리 창조될 것 말씀하심(계 7:13~14)
- 하나님의 씨로 난 한 가족 되기 위해 추수 → 천국 곳간 12지파 소속
⇒ 믿음의 가족이 되자.
