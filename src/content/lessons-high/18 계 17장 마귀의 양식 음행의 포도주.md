< 계 17장, 마귀의 양식 음행의 포도주 >
[핵심]
- 천사 → 새요한 알려줌
- 음녀의 비밀, 일곱 머리와 열 뿔 가진 짐승의 비밀
- 예수님 : 사로잡힌 자들 빼내실 것
- 짐승 → 음녀 심판 : 음녀의 나라 차지할 것
[서론]
- 제목 : 마귀의 양식 음행의 포도주
- 일곱 대접을 가진 일곱 천사 중 하나 → 요한 : 보여줌
: 많은 물 위에 앉은 큰 음녀가 받을 심판
- 음녀의 음행의 포도주 → 땅의 임금들, 땅에 거하는 자들 : 음행
→ 음녀와 일곱 머리 열 뿔 가진 짐승의 비밀과 실체, 음행의 포도주 알아야 함
⇒ 계시록 성취 때 하나님 양식, 마귀의 양식 구별 → 하나님의 참 양식 먹어야 함
[본론]
- 계 17:1~2 천사 → 요한 : 많은 물 위에 앉은 큰 음녀가 받을 심판 보여줌
- 큰 음녀 : 청지기 교육원 목자 ‘땅 씨(가명)’
- 음행한 땅의 임금들, 땅에 거하는 자들
: 음녀 소속 각 교단의 목자들과 소속 교인들
⇒ 마귀의 양식 음행의 포도주(사단의 교리 주석) 먹고 정신을 못차림
- 주 재림 때 신앙인들이 구분해야 할 양식
- 먹어야 할 양식
: 예수님 → 이긴자 : 감추었던 만나(계 2:17), 계시 말씀
- 마귀의 양식
: 마귀 → 음녀 : 음행의 포도주(선악과, 주석)(신 32:33, 단 4:20~22)
⇒ 만국 무너뜨림
- 계 17:3~6 성령 → 요한 : 음녀의 비밀 알려줌
- 음녀가 앉은 많은 물
계 17:1 많은 물 = 일곱 머리 열 뿔 가진 짐승(계 17:3)
- 일곱 머리 : 선민 장막 멸망시킨 일곱 거짓 목자
청지기 교육원 일곱 목자
- 열 뿔 가진 짐승 : 장막성전 출신 목자 ‘뱀 씨(가명)’
- 자줏빛 붉은 빛 옷, 각종 보석 : 사단의 교리, 교법
- 음녀의 이름 바벨론
: 음녀 → 하나님 선민 멸망시킨 멸망자
구약 시대 이방 나라 바벨론 빙자(하나님의 선민 멸망시킴)
- 큰 음녀가 땅의 음녀, 가증한 것들의 어미인 이유
: 마귀의 교리 주석 등으로 양육한 존재이기 때문
→ 마귀의 교리를 받은 거짓 목자들과 소속 교인들
- 바벨론 음녀의 실체를 아는 자
: 성령 → 사건의 현장에서 비밀을 직접 보고 들은 자 이긴자 새요한(계 22:8) 뿐
- 계 17:7~13 천사 → 요한 : 음녀가 탄 일곱 머리 열 뿔 가진 짐승의 비밀 알려줌
- 일곱 머리 : 일곱 산, 왕
= 청지기 교육원 일곱 교회의 일곱 목자
- 여덟째 왕 : 일곱 멸망자 제치고 마지막에 실권을 잡는 장막성전 출신 목자 ‘뱀 씨’
- 열 뿔 : 여덟째 왕에게 속한 열 명의 권세자(장로 직책자)
- 계 17:14~18 어린 양 예수님께서 부르시고 빼내시며 진실한 자들
: 큰 음녀, 일곱 머리와 열 뿔 가진 짐승 이김 → 증거장막 성전 나오게 됨
: 주 재림 때의 유월절
- 음녀가 받을 심판 : 열 뿔, 여덟째 왕 → 음녀 미워하고 망하게 하고 살을 불러 사름
: ① 음녀의 음행한 수치 드러내고 그의 교리 양식 삼아 배를 불림
② 돌아서서 잘못되었다며 음녀 배반, 심판하는 것
[결론]
- 천사 → 요한 : 광야 데리고 감
: 많은 물 위에 앉은 음녀, 일곱 머리와 열 뿔 가진 짐승(멸망자의 비밀) 알려줌(암 3:7)
- 음녀 : 음행의 포도주(거짓 교리 주석)
: 자기 소속 목자, 교인들 양육, 만국(모든 교회) → 음행하게 함(계 18:3, 계 17:2)
- 예수님 : ① 새요한과 함께 짐승에게 사로잡힌 하나님의 백성들 빼내심
② 열 뿔 가진 짐승 → 음녀 심판, 음녀의 나라 차지할 것 알려주심
- 주 재림 때(오늘날) 나는
: 하나님의 양식 계시 말씀 ↔ 마귀의 양식 음행의 포도주 주석 구분
예수님 → 이긴자 : 하나님의 양식, 계시 말씀 들어 먹고 깨달아 천국, 영생 이르자
