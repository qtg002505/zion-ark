< 계 18장, 만국을 무너뜨린 사단과의 결혼 >
[핵심]
- 계 18장 : 계 17장 음녀 심판 후 귀신의 나라 바벨론 심판, 하나님 백성 불러내어 구원
음행의 포도주 : 만국 무너뜨림
[서론]
- 제목 : 만국을 무너뜨린 사단과의 결혼
- 말세 때(오늘날) 귀신의 처소 바벨론 → 음행의 포도주 : 만국 무너뜨림, 땅의 왕들 : 음행
- 사단과의 결혼 : 만국의 교인들 → 바벨론의 악령 : 영적 행음한 것
- 오늘날 만국 무너뜨린 바벨론의 정체,
어디에서 나와 어디로 가야 구원에 이르는지 확인해야 함
[본론]
- 계 18:1~3 계 17장 음녀 심판 후 하늘 → 다른 천사 : 큰 성 바벨론 무너졌음 알림
- 영적 바벨론 실체 : 음녀와 일곱 머리와 열 뿔 가진 짐승의 조직체(청지기 교육원)
계시록 성취 때 하나님의 선민 장막(장막성전) 멸망시킴
- 바벨론이 무너졌다 : 청지기 교육원 → 심판 받아 끝난 것
- 만국 : 배도한 장막성전 포함한 바벨론 소속 세상 모든 교회
- 음행의 포도주 : 거짓 교리 곧 주석
(음녀 : 악령과 교제하여 받음, 선악과와 같음)
- 만국이 무너졌다
: 음녀가 주장하는 마귀 교리(주석) → 이 땅 모든 목자, 교회 : 영적 무너진 것
- 계 18:4~8 하늘 : 다른 음성 → 하나님 백성 : 심판 받는 바벨론에서 나오라!
: 예수님께서 새요한과 하나되어 → 바벨론 잡혀 있는 성도들
불러내고 빼내심(계 17:14) ⇒ 이루어짐
- 바벨론에서 나와 어디로 가야 구원받는가
: 이긴자가 있는 신천지예수교 증거장막성전(계 7장, 계 15:5)
- 계 18:6~8 하나님 : 직접 바벨론 심판
: 바벨론 장막성전에 행한 멸망의 일 배로 돌려받음(계 13:10, 계 11:2)
- 계 18:7 여황 : 모든 목자 위 가장 높은 자
- 과부가 아니라 함 : 신랑 되신 예수님께서 함께하신다는 거짓말로 위장한다
- 바벨론 음녀의 조직 : 사망, 애통, 흉년 겪음, 불로 심판 받음
- 계 18:9~11 땅의 왕들, 상고들 : 가슴을 치며 울고 애통해 함
: 계시 말씀(심판하는 불) → 바벨론 사른 것
- 애통해하는 이유 : 바벨론 심판 받음 → 다시는 바벨론의 거짓 교리 믿는 자 X
- 계 18:12~14 바벨론 상품들 : 사단의 교리, 교법, 조직
- 바벨론이 탐하던 과실 : 바벨론에 사로잡혔던 하나님의 백성들
- 하나님의 백성들 : 바벨론에서 떠났다 : 바벨론 → 시온산 전도(계 18:4)되어 온 것
- 계 18:15~19 바다의 선장, 선객, 선인들 : 바벨론 망한 것 보고 울고 애통해 함
- 바다 : 세상
- 배 : 교회
- 선장 : 목자 / 선객들 : 교인들 / 선인들 : 교역자들, 직분자들
- 바다에서 일하는 자들 : 바벨론 소속 → 세상 파견된 자들
- 계 18:20 하나님 → 바벨론 심판 : 순교한 영혼들 피의 신원
⇒ 하늘, 성도들, 사도들, 선지자들 기뻐하고 즐거워하라
- 계 18:21~24 바벨론 심판 받아 없어짐 → 바벨론 모든 것들 : 더불어 사라짐
- 바벨론 거문고, 풍류, 퉁소, 나팔, 맷돌 소리 : 사단의 교리와 주석
- 세공업자 : 사단의 교리를 연구하는 목자
→ 바벨론 교리를 들으려 하는 사람들 : 없어짐 ⇒ 모두 저절로 사라짐
- 마귀와의 결혼 없어짐(계 18:23)
: 마귀와 성도의 영 신랑과 신부처럼 결혼 하나가 되는 일 완전히 없어짐
- 선지자들의 피가 바벨론 성 중에 보임
: 계 18장 바벨론 심판 → 역대 순교자들 죽여 온 귀신의 정체 드러난 것
[결론]
- 계 18장 바벨론 심판 : 만국 → 사단과 결혼하는 일 끝남
- 바벨론 : 음행의 포도주 → 만국 교인들 사단과 영적으로 행음하게 함
- 계 19장 어린양 예수님과의 혼인 잔치 시작됨
- 계시록에서 밝힌 하나님 소속, 사단의 소속 바르게 구분
⇒ 귀신의 처소 바벨론 → 시온산 증거장막성전 : 구원에 이르자
