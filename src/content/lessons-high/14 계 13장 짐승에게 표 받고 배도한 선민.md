[핵심]

- 바다에서 나온 짐승(승) vs 하늘 장막 성도들(패)
땅에서 나온 짐승 → 장막 성도들 : 짐승의 표 ⇒ 장막 멸망 받음
[서론]
- 제목 : 짐승에게 표 받고 배도한 선민
- 계 12장과 계 13장과의 관계
① 기록된 순서 : 계 12장 먼저 ↔ 계 13장 : 먼저 일어난 사건
② 계 13장 : 짐승, 바다 → 장막 들어오는 과정 기록
계 12장 : 바다 짐승, 여자가 낳은 아이에게 지게 되어 장막에서 쫓겨나는 장면 기록
③ 계 13장의 전쟁 : 1차전 / 계 12장의 전쟁 : 2차전

- 계 13장은 언제, 어디서 이루어지는 일인가?
- 언제 : 주 재림 때(계시록 성취 때)
- 어디서 : 계 13:6 배도한 하늘 장막
계 2~3장 일곱 별 일곱 사자가 있는 일곱 금 촛대 장막
- 무엇 : 약 2천 년 전 환상으로 기록된 계시록의 예언의 실상(실체)이 나타남
- 계 13:1~10 바다 : 7머리 10뿔 짐승 → 하늘 장막 : 성도들과 싸워 이김
- 바다에서 나온 짐승 : 세상에서 나온 거짓 목자

: 종교 세상(주관하는 짐승 : 거짓 목자(잠 30:2~3)
- 짐승에게 달려 있는 머리와 뿔
① 머리 : 멸망자에게 속한 일곱 목자
② 뿔 : 열 권세자(계 17:9~10, 12)
- 이 거짓 목자, 하늘 장막을 어떻게 멸망시켰을까

- 바다에서 올라온 짐승(승) vs 하늘 장막 성도들(패) → 42달 일할 권세 받음
= 42달 동안 하늘 장막에서 설교하고 교회를 다스리는 권한
- 42달 : 1980년 9월 ~ 1984년 3월
짐승과 같은 거짓 목자 → 하나님의 성도들 다스리게 됨
- 42달 기간 중요한 이유
: 42달 동안 거짓 목자들 비진리, 교권 → 장막 성도들 핍박 : 멸망 당하기 때문
- 그 이후 계 12장 : 철장을 가진 아이와 그 형제들 싸워 이김
→ 장막에서 용의 무리 쫓겨남 하나님의 나라, 구원 있게됨
- 바다에서 올라온 7머리 10뿔 짐’만’ 하늘 장막 성도 훼방한 것 X

- 계 13:11~18 땅에서 올라온 짐승
- 땅 짐승 : 일곱 금 촛대 장막 출신 → 멸망자와 하나된 육체
계 2장 니골라, 발람 / 계 8~9장 쑥 별
∴ 실체 : 장막성전 출신 ‘뱀 씨’(가명)
- 장막 출신 거짓 목자는 하늘 장막을 어떻게 멸망시켰을까
- 땅에서 올라온 짐승 : 우상 만듦 → 장막 성도들 우상에게 경배하게 함
- 비유한 우상 : 합 2:18 거짓 스승(목자)
= 멸망자가 세운 거짓 목자들
∴ 실상 : 짐승 같은 거짓 목자 : 안수 한 번 받음
→ 목사가 된 장막성전 전도사 17명
- 본래 장막성전 전도사 → 멸망자와 하나됨
: 세상 교법 → 장막 성도들의 영을 죽이는 우상
- 이들을 따르지 않는 자들, 제명이나 출회를 시켰음
- 바다 짐승, 땅 짐승, 우상 하나되어 하나님의 선민 장막 성도들 어떻게 멸망시켰을까?
- 666표

- 오른손 표를 받는 것

∴ 짐승에게 경배하고 표 받은 사건의 실상
