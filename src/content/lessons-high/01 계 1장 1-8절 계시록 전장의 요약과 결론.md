< 계 1:1~8, 계시록 전장의 요약과 결론 >
[핵심]
- 예수님의 계시 : 하나님 → 예수님 → 천사 → 새요한 → 종들
- 속히 될 일 : 계시록 전장의 사건
- 새요한 : 계시록 성취 때 계시록 전장의 사건을 보고 들은 것을 증거하는 예수님의 사자

[서론]
- 제목 : 계시록 전장의 요약과 결론
- 요한계시록이란
① 신약의 예언서
② 성경 66권 중 하나님의 6천 년 모든 역사를 마감 짓는 책
③ 계시록 成 → 하나님의 뜻하신 목적 완성
계시록의 예언 : 약 2천 년간 봉한 책 → 누구도 실체를 알 수 없었음
→ 예언 成 : (실체를) 알 수 있게 됨
새 언약 계시록 : 언제, 누구를 통하여 예언의 실체를 깨달을 수 있는가.

[본론]
- 요한계시록이란
: 언제 / 약 2천 년 전
누가 / 예수님의 제자 사도 요한
어디서 / 밧모섬에 유배되어 있을 때
무엇을 / 장래에 이룰 것을
어떻게 / 환상으로 계시를 받아 기록한 예언서
- 예언의 말씀 미리 알려주신 이유
: 예언을 이룰 때 보고 믿게 하기 위함(요 14:29)
- 실상 계시
: 계시록 성취 때 요한을 빙자(호 12:10)
→ 한 목자 택하여 예언 성취된 실체를 보여주심
- 계 1:1~8 계시록 전장을 요약한 핵심과 결론(요한이 계시록 전장 보고 들음)
계 1:9 ~ 계시록 사건의 시작
- 요한계시록 = “예수 그리스도”의 계시라고 하는 이유
- 계시(啓示) : 열어서 보여 준다
봉한 책의 인 → 예수님께서 떼어 이루시고 보여 주셨기 때문
- 계시록 성취 때 열어서 보여 주신 계시의 내용
= 예언 X, 예언을 이룬 실상
- 실상 계시 전달 과정
① 하나님 → 예수님(계 5장) : 일곱 인으로 봉한 책
* 목적 = 하나님께서 속히 될 일을 종들에게 보이시려고
② 예수님 : 인을 떼어 열어, 책에 기록된 것 이루심(계 6, 8장)
③ 계 10장 열린 책 : 천사 → 새요한 : 하나님의 종들 전하라 지시
- 종들에게 보이시려고 하는 “반드시 속히 될 일”은?
= 계시록 전장의 사건
- 계시를 보이려는 종들
: 계 7장 하나님의 나라 영적 새 이스라엘 12지파
인 맞은 144,000명과 예수님의 피로 죄 사함 받은 흰 무리
- 계시록 성취 때 계시록 전장의 실상을 보고 들은 사람(계 22:8)
: 사도 요한을 빙자한 새 요한(가명)
새요한이 전하는 하나님의 말씀 = 계 10장 받아먹은 열린 책의 말씀
- 새요한
: 예수님의 사자 → 교회들 : 자기가 본 계시록 전장의 실상 증거(계 22:16)
- 예언의 말씀 읽는 자, 듣는 자들, 지키는 자들은?
- 예언의 말씀 : 계시록 전장의 사건
- 읽는 자 : 계 10장 열린 책 받아먹은 새요한(단순히 읽는 자 X, 뜻을 아는 자)
- 듣는 자들 : 새요한에게 배우는 백성, 나라, 방언, 임금들
곧 죄 가운데 있는 모든 교회와 교인들(계 10:11)
- 예수님 : 약속하신 목자 새요한 → 계시록 전장 보고 듣고 전하게 하심
오늘날 모든 신앙인들 : 새요한에게 열린 책의 계시 말씀 증거받아야 함.
- 지키는 자들 : 읽는 자 곧 새요한을 포함한 12지파 144,000과 흰 무리

- 계 1:4, 요한이 편지하는 ‘아시아에 있는 일곱 교회’는?
- 일곱 교회 = 당시 소아시아 일곱 교회 X
계 1:1~8 계시록 전장 요약한 것 / 계 1:20 일곱 교회와 일곱 별 = 비밀
기록할 당시 인명, 지명 빙자 기록(호 12:10)
실제 편지하는 때 : 계시록 성취 때
- 실상
: 계 1:9~ 예수님께 택함 받은 새요한 → 계 2~3장 편지한 것
편지하라는 지시 받은 후
아시아 일곱 교회 실체 = 하나님의 장막 곧 장막성전(계 2~3장)
- 계 1:5~6 예수님의 피로 죄에서 해방된 자들은?
: 계 5:9~10 예수님의 피로 사서 하나님의 나라와 제사장 삼은 자들
- 실체 : 예수님의 피의 효력이 나타나는 오늘날
하나님의 씨로 나서 추수되어 인 맞은 12지파 144,000
- 계 1:7 예수님께서 구름타고 오신다는 것
= 영으로 오신다는 것(육안으로는 보이지 않음)
- 찌른 자 = 계 11장 주를 모신 두 증인을 찌른 무저갱에서 올라온 짐승(거짓 목자)
- 하나님 : 알파와 오메가라 하신 것
= 시작과 끝,
아담 범죄 이후 회복의 역사 시작하신 하나님
→ 계시록 이루심으로 모든 일 완성하신다는 것
◈ 결론
계 1:1~8 계시록 전장의 사건 요약한 핵심과 결론 = 성경 6천 년 역사의 결론
계시록의 예언 : 하나님의 이루실 천국 비밀 일곱 인 봉해져 아는 자 X
→ 계시록 성취 때 : 계시록 전장의 사건을 보고 들은 새요한 통해 실체 알게 됨
신약의 약속의 목자 새요한을 만나 계시 말씀 증거받고 구원에 이르시기를 바랍니다.
