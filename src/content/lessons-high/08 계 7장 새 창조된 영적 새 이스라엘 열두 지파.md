- 계 6장 : 부패한 이전 시대 끝내심
→ 계 7장 새로 창조한 하나님의 나라
= 인 맞은 144,000과 예수님의 피로 죄 사함 받은 흰 무리
= 하나님의 약속의 새 나라 새 민족 영적 새 이스라엘 12지파
⇒ 성경 66권의 목적, 계시록의 목적, 하나님의 마지막 역사
본론]
- 계 7:1 이 일 후
- 이 일 후
: 사건의 전, 후를 알려주는 표현(총 6번 등장)
- 계 7:1 ‘이 일’
: 계 6장 선천 해, 달, 별 : 대풍 심판 → 없어진 사건
= 처음 하늘 처음 땅(하나님의 백성들) → 없어지게 된 내용
∴ 마 8:12 “나라의 본 자손
→ 바깥 어두운 데로 쫓겨나 슬피 울며 이를 간다” 말씀 成 사건
- 네 모퉁이에 선 네 천사장 : 땅의 사방의 바람 붙잡음
- 이유 : 하나님의 종들 144,000 인치기 위함
인을 다 치면 → 다시 바람 놓아 심판 이어짐

- 계 7:2 해 돋는 데 → 하나님의 인을 가진 천사 올라옴
- 해 돋는 곳 = 하나님의 역사가 시작되는 계시록 성취 현장
시 84:11 해 = 하나님
- 천사가 가져오는 인(印) : 하나님 이름 기록된 하나님의 도장
① 하나님의 이름 = 하나님의 말씀(요 1:1)
② 말씀을 받은 목자 = 하나님의 인(학 2:23)
- ‘인’에 대해
- 인을 친다 = 생각, 마음에 하나님의 말씀 기록하여 주는 것
- 인을 맞는다 = 하나님의 말씀 인정, 생각과 마음에 기록하는 것
- 인치는 ‘우리’
① 하나님의 인을 가지고 오는 천사
② 계 10장 열린 책 받아먹은 목자
③ 이 목자에게 인침 받은 12지파장 → 각 지파 1만 2천씩 인치는 사명
↔ 사단의 인(표), 사단의 도장 : 사단의 말, 거짓말(비진리) 기록
= 계 13장 666 표현
- 하나님의 인 맞은 자 : 하나님의 소유(소속) → 천국
사단의 표 받은 자 : 사단의 소유(소속) → 지옥
∴ 우리는 반드시 하나님의 인 맞아야 함.
- 계 7:4~8 인 맞은 종들의 수 = 각 지파 1만 2천 명 → 12지파 144,000
- 마지막 때 창조되는 144,000
약 2,600년 전 예레미야 예언
→ 초림 예수님께서 뿌리신 하나님의 씨 : 2천 년간 자라 익은 곡식
→ 추수한 하나님의 첫 열매들,
= 진리의 말씀으로 낳은 하나님의 아들들(계 14:14~16, 약 1:18)
= 하나님의 인 맞은 자들,
∴ 구원받는 새 나라 새 민족 중 가르치는 제사장
영적 새 이스라엘의 목자들
- 오늘날 신천지 : 새 언약 이행 시험 항시 실시(히 8:10~12)
이유 : 제사장의 자격, 자질 갖추게 하기 위해
새 언약 계시록의 말씀을 마음 기록했는지 확인

- 12지파
본문 12지파 : 야곱(이스라엘)의 12아들들의 이름
오늘날 창조 → 영적 새 이스라엘 12지파의 이름 : 예수님의 12제자의 이름
→ 예수님의 약속대로 이루어진 것(마 19:28)
순교한 예수님의 12제자 → 12기초석,
이 땅 12지파장과 하나되어 신천지 12지파 함께 치리하고 다스리기 때문(계 21:14)
- 신천지 12지파 보좌 구성 : 1995년 3월 14일 수원 공설운동장 성취
- 계 7:9~14 ‘이 일 후’
- ‘이 일’ = 인 맞은 144,000 창조의 일
인치는 일 → 다시 바람이 붊 = 큰 환난
→ 나라, 족속, 백성, 방언 : 셀 수 없는 흰 옷 입은 큰 무리가 나옴
- 흰 무리 : 자신들이 속한 각 교단 → 하나님 말씀 깨닫고 나온 자들
예수님의 피(말씀) → 죄 사함 : 마음, 행실 깨끗게 된 자들(요 15:3)
= 영적 새 이스라엘의 백성들
- 계 7:15~17 그들 : 하나님 보좌 앞, 하나님께서 함께하심
- 그들 : 144,000과 흰 무리
→ 하나님의 성전, 증거장막 성전에서 하나님 섬김
하나님의 장막( = 영계 천국) → 임하여 함께 있게 됨
⇒ 다시는 사망이 없는 하나님의 천국 나라 완성(계 21:1~6)
◈ 결론
- 성경에 약속한 하나님 소속 백성들 : 영적 새 이스라엘 12지파
12지파 소속 144,000 : 인 맞은 자들, 새 목자
144,000 인치는 일 후 큰 환난
→ 예수님의 피에 옷을 씻은 셀 수 없는 흰 무리 백성들 나옴
- 이들(144,000과 흰 무리)
: 오늘날 하나님이 함께하시는 새 나라 새 민족 12지파
구원 영생 받을 수 있는 자들
- 이를 이루는 것 : 성경 66권 목적, 계시록의 목적
= 하나님의 마지막 역사
∴ 12지파 속하여 하나님께 인정, 구원받는 참 신앙인 되자.
