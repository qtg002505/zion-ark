< 계 12장, 용과 하나님과의 전쟁 >
[핵심]
- 하늘 장막이라는 한 장소 : 배도자, 멸망자, 구원자 출현
→ 하는 일, 행동 따라 실체 드러나게 됨
- 이때 만국을 다스릴 아이 : 용과 싸워 이김
→ 하나님의 구원, 능력, 나라, 권세 이루어짐
[서론]
- 제목 : 용과 하나님과의 전쟁
계시록 성취 때 ‘하늘 장막’(한 장소)
: 하나님 소속 영육 vs 사단 소속 영육 간 영적 전쟁
- 만국을 다스릴 아이와 그 형제들 : 용의 무리와 싸워 이기는 일
→ 이 때 : 하나님의 나라, 구원, 능력, 그리스도의 권세 O
※ 천국, 영생 소망하는 신앙인 : 반드시 깨달아야 함
[본론]
- 주 재림 때 : 계시록 때의 전쟁 : 배도자, 멸망자, 구원자 세 조직 간의 전쟁
- 계 12장 전쟁 장소 : 계 13, 2~3장 사건 있었던 곳과 동일한 하늘 장막
= 일곱 별 일곱 금 촛대 장막
- 계시록 : 전 세계적 이루어지는 사건 X, 선민 장막 : 한 장소에서 이루어지는 사건
- 이 장소 : 하나님 소속 영, 육 vs 용의 소속 영, 육 간 영적 전쟁(엡 6:17)
- 계 13장 : 하나님 소속 선민 장막 vs 용의 소속 이방 멸망자(1차전)
① 결과 = 선민 장막 패함
② 이방 멸망자에게 패한 이유
: 언약(새 언약)의 말씀 지키지 못했기 때문(신 28장)
- 계 12장 : 멸망자 vs 약속의 목자와의 전쟁(2차전)
① 결과 : 하나님의 약속의 목자 이기게 됨
② 이길 수 이는 무기 : 예수님의 피와 증거하는 말(계 12:11)
- 이긴자와 진 자의 증거
① 전쟁 때 진 자의 증거 : 일곱 갈래로 갈라짐(신 28:25, 7)
② 이긴자인 증거 : 이스라엘 → 12지파 창설(계 7장)
- 사건 이루어지는 순리상 : 계 13장 사건 후 계 12장 사건
- 해, 달, 별 입은 여자 : 7머리 10뿔 가진 용 앞 아이 해산하려 함
- 아이 계 12:10~11 용과 싸워 이김
→ 장차 : 철장 만국 다스릴 남자아이 여자 아이 배어 해산하는 일
= 큰 이적(계 12:1~2)
- 천국 소망 신앙인 : 만국을 다스릴 아이를 찾아야 함
- 계 2~3장 약속한 복을 받는 신약의 약속한 목자
: 계 21:7 하나님의 아들 → 유업을 받게 되는 구원자이기 때문
- 하늘 : 일곱 별이 있는 일곱 금 촛대 장막, 실상 = 장막성전
- 해를 입은 여자 : 장막성전을 다스리는 목자
- 붉은 용 : 사단, 마귀
- 용의 무리 실체 : 청지기 교육원
- 해를 입은 여자 낳은 아이와 형제들
: 예수님의 피와 증거하는 말 → 용의 무리와 싸워 이김 ⇒ 용 쫓겨남
- 이 떄 : 하나님의 구원, 능력, 나라, 그리스도의 권세 있게 됨
- 전쟁에서 이긴 자 → 이스라엘 : 약속한 복(계 2~3장) 받게 됨
⇒ 영적 새 이스라엘 12지파 창조
- 영원한 하나님의 나라(단 2:44)
: 신천지예수교 증거장막성전(계 7장, 계 14장, 계 15장, 계 21:1)
- 용 : 전쟁에서 패함 → 하늘에서 쫓겨나고, 만국을 다스릴 아이를 낳은 여자 핍박
- 아이를 낳은 여자
: 낯을 피하여 광야로 도망(계 12:6)
→ 광야 : 1,260일 간 이방 교리로 양육 받게됨(단 11:13)
- 전쟁 패함 → 하늘에서 쫓겨난 용
: 예수님의 증거를 가진 자들과 싸우기 위해 바다 모래 위(세상 교인들) 군림
= 어린 양의 피와 증거하는 말로 싸워 이긴 아이와 그 형제들
- 모든 세상 교인들 : 용과 싸워 이긴 이긴자를 만나 살길 찾아야 함
- 이유 : 계 12장 성취 때 약속한 목자 이긴자와 하나가 되어야만
하나님의 나라와 구원에 이를 수 있기 때문

[결론]
- 계 12장, 하늘 장막에 용이 들어와 있는 42달 내
해, 달, 별 입은 여자로부터 난 아이 : 장차 만국을 다스릴 구원자
- 아이와 형제들 : 어린 양의 피와 증거하는 말 → 용의 무리와 싸워 이김
⇒ 이 때 : 하나님의 나라, 구원, 능력, 그리스도의 권세 있게 됨
- 이 사건 = 계 12장 ‘용과 하나님과의 전쟁’
- 계시록 성취 때(오늘날) 천국 소망 모든 신앙인
: 용과 싸워 이긴 약속의 목자 → 재창조된 하나님의 나라
⇒ 하나님의 백성 되어 구원받기를 바람
