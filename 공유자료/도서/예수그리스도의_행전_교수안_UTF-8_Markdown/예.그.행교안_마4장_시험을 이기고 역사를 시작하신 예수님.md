# 捤獥 汤捯 慤桥 마태복음 4장 <시험을 이기고 역사를 시작하신 예수님

- ▶1-11절 : 시험을 이기신 예수님

예수님 : 성령으로 잉태, 하나님의 아들이라 증거, 성령과 하나됨

성령의 인도로 마귀에게 시험

사도요한 : 성령에 이끌려 광야에서 시험(계 17:1-6)

◎첫 번째 시험 마귀 : 하나님의 아들이면 돌들로 떡덩이가 되게 하라

예수님 : 사람이 떡으로만 살것X, 하나님의 말씀O(신 8:3)

◎두 번째 시험 마귀 : 하나님의 아들이면 뛰어내리라,

천사들을 명하여 지키시리라(시 91:11-12)

예수님 : 주 너의 하나님을 시험치 말라(신 6:16)

◎세 번째 시험 마귀 : 내게 엎드려 경배하면 모든 것을 주리라

예수님 : 주 너의 하나님께 경배하고 다만 그를 섬기라(신 6:13)

- ※마귀가 천하를 주겠다고 할 수 있었던 이유?(눅 4:6)

: 하나님이 아담 범죄 이후 범죄한 인류세계를 마귀에게 내어주셨기 때문

But? 마귀는 일시적인 이 세상 임금일뿐, 결말은 영원한 지옥 불에 들어감

- ※사단의 말

사단의 말은 하나님의 말씀이라고 착각될 만큼 간교하다. 하와도 처음에는 하나님의 말씀으로 뱀의 유혹을 뿌리치려 했으나 뱀의 말에 혼란에 빠져 넘어졌다. 사단은 예수님을 시험할 때도 성구를 인용할 만큼 하나님의 말씀과 세계에 대해 많이 알고 있었다. 그러므로 사단의 시험을 이기려면 사단을 꺾을 수 있는 해박한 성경 지식과 지혜가 있어야 하며 신앙의 절개를 지키려는 확고한 신념이 있어야 한다.

◎이와 같이 하나님의 아들이신 예수님께서 우리 사람처럼 사단에게 시험받는 일을 겪으셨기에, 우리의 연약함을 잘 아시고 우리가 당하는 시험을 이길 수 있도록 도와주신다.

히 2:18 “자기가 시험을 받아 고난을 당하셨은즉 시험받는 자들을 능히 도우시느니라”

- ▶12-25절 : 갈릴리에서 역사를 시작하신 예수님

사 9:1-2(예언) → 마 4:15-16(성취) 갈리리에서 역사 할 것

*갈릴리 : 이방이라 불리던 멸시받는 지역, 영적으로 가장 캄캄한 ‘흑암의 땅’

◎세례요한이 자기에게 맡겨진 역사를 마치자 예수님께서는 가버나움으로 거처를 옮기시고 본격적으로 “회개하라. 천국이 가까이 왔다.”고 하시며 천국 복음을 전하시기 시작했다. 이 때에 예수님의 나이는 30세였다.
