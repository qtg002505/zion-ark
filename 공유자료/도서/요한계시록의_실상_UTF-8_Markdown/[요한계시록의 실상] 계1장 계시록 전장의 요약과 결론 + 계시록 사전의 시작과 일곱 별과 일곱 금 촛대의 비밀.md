# 요한계시록의 실상

## 계 1:1-8 계시록 전장의 요약과 결론

[확인 필요: 원문]

- 사건 현장 : 하나님의 일곱 금 촛대 장막(주의 예비 장막)

대한민국 과천 소재 장막성전

- 성취 시기 : 주 재림 때, 1977년 가을

- 출현 인물 : 영계 - 하나님, 예수님, 천사

ĄĀ 육계 - 사도 요한(새요한), 일곱 금 촛대 장막의 일곱 사자와 성도들

- 요한계시록 - 약 2천 년 전 사도요한이 밧모섬에서 예수님의 계시를 “환상”으로 보고 기록한 책(예수님의 계시를 요한이 받아 기록했기 때문에 붙혀진 이름)

- ·계 1:1-8 계시록 전장의 요약과 결론

- ·계 1:9-20 계시록 사건의 시작

## 1절 : 예수 그리스도의 계시

### 1) 예수님의 계시

- •계시(啓示) : 열어서 보인다는 뜻

- →봉해진 말씀을 열어 이루시고 그 실상을 나타내어 보이는 것

- •예수 그리스도의 계시 : 봉해진 하나님의 책을 예수님이 펼치시고 이루셨기 때문

- -구약 계시 : 사29장, 겔3장 → 예수님

- -신약 계시 : 계5장, 계10장 → 새요한

- •계시의 종류 ┌ 사단 : 거짓 계시

- └ 하나님 : 참 계시 - 환상계시 : 장래 이룰 일을 이상으로 미리 보여줌

- - 실상계시 : 약속한 예언을 실물로 이루어 보여줌

*2천 년 전 사도 요한이 받았던 계시는 환상계시

- •계시의 중요성 : 하나님을 알게 되고 영생을 얻음(마 11:27, 요 17:3, 갈 3:23-29)

### 2) 속히 될 일(계 21:16 참고)

: 계시록 전장 사건

구약 예언 : 1,500년 간 전파 → 초림 때 3년 만에 성취

신약 예언 : 2,000년 간 전파 → 재림 때 30여년 만에 90%까지 이룸

### 3) 계시 받을 종들(계7장 참고)

: 영적 새 이스라엘 12지파의 144,000과 흰무리(계10장, 7장)

### 4) 계시 전달 과정(본문 1절)

: 하나님→예수님→천사→(새)요한→종들

열린 책을 받아먹은 새요한에게만 ‘예수 그리스도의 계시’를 배울 수 있음.

## 2절 : 하나님의 말씀과 예수님의 증거

### 1) 하나님의 말씀

: 하나님과 천사들로부터 들은 말씀(계10장에서 받아먹은 열린 책의 말씀)

### 2) 예수님의 증거

: 계시록 전장의 말씀과 그 이루어진 사건

- 계2-3장의 편지 - 요한 : 예수님의 말씀을 대언하는 사람(계 22:8, 16)

- →요한의 증거 = 예수님의 증거

(→초림 예수님의 증거 = 하나님의 증거)

### 3) 요한이 본 것

: 계시록의 사건(계1장~계22장까지의 실체들)

- →참 증거란 보고 들은 자만이 할 수 있음. 예수님의 뜻에 따라 계시록에 기록한 모든 것을 직접 보고 설명을 들은 요한의 증언이 참된 증거임을 알아야 함.

- →계시록 성취 때에는 계시록의 예언과 실상을 사도요한과 같은 목자(새요한)가 출현하여 증거함. 실상은 예언 성취 때의 사람이 보고 증거 할 수 있기 때문.

## 3절 : 계시록을 지키는 자들이 받을 복

### 1) 이 예언의 말씀을 읽는 자와 듣는 자들

- •읽는 자(뜻, 비밀, 실체를 아는 자) : 펼쳐진 책을 받아 먹은 새요한(계10장)

- •듣는 자들 : 종들 계10장 - 백성과 나라와 방언과 임금들

계7장 - 인 맞은 144,000명과 흰 무리

### 2) 그 가운데 기록한 것과 기록한 때

- •기록한 것 : 계시록의 약속의 말씀

- →계시록의 약속의 말씀을 알지 못하면 천국도 구원도 얻지 못함(계 22:18-19)

### 3) 지키는 자들이 받을 복

- •지키는 것 : 기록된 예언과 실상을 믿고 지키는 것

계시록을 지키지 않는 자 - 예수님을 믿지 않는 자

계시록을 지키는 자 - 예수님을 믿는 자 → 예수님의 계시이기 때문

- •받을 복 : 죄 사함과 영생, 하나님의 나라와 제사장

## 4-6절 : 하나님의 나라와 제사장

### 1) 아시아의 일곱 교회의 비밀(←2-3장)

: 아시아의 일곱 교회(빙자한 비유) → 일곱 금 촛대 장막(실체)

- •요한은 (소)아시아의 일곱 교회에 실제로 편지한 적이 없다.(환상으로 편지한 것)

역사적 자료와 근거가 남아 있는 것이 없고, 요한이 에베소 교회 담임이었는데 요한이 요한에게 편지를 보낸다는 것은 말이 맞지 않다. 현재 일곱 교회들은 다 무너져 그 터만 남아 있다. 그러니 그 일곱 교회에서 계시록의 사건이 이루어질 수는 없다.

### 2) 예수님의 피로 죄에서 해방

: 하나님의 나라와 제사장 삼으심(계 1:5-6, 계 5:9-10, 계 12:11)

하나님의 아들이 되어 유업 이을 자가 됨(갈 3:26, 4:6)

- →이 세상 어느 것으로도 없앨 수 없는 우리의 죄를 피흘리심으로 사하여 주신 은혜에 감사해야 함(예수님의 피 흘리심과 계시록 성취 때의 나라와 제사장의 관련성)

### 3) 하나님의 나라와 제사장

: 하나님의 법을 생각과 마음에 기록하여 새 언약의 말씀을 지켜야 함(히 8:10)

## 7절 : 구름 타고 오시는 예수님을 찌른 자들

### 1) 구름 타고 오시는 예수님과 그를 찌른 자들

- •‘구름‘ 타고 오심 : ‘영‘으로 오심(겔1장, 출19장, 마17장, 눅9장, 행1장)

- •찌른 자들 : 예수님을 대신하여 예수님의 일을 하는 두 증인을 찌른 자들(계11장 멸망자)

*참고성구 : 요 14:9-10, 요 15:18, 요 15:23

### 2) 애곡하는 자

: 하나님께 택함 받고도 배도하여 버림받은 장막 성전의 성도들

이 예언의 말씀을 받고도 믿지 않은 모든 자들

## 8절 : 알파와 오메가

- •알파 : 시작(예언) / 오메가 : 끝(성취)

: 아담 범죄 이후 회복의 역사를 시작하신 하나님께서 계시록을 이루심으로 모든 일을 완성 하신다는 것을 의미

- →모든 것을 시작하신 분 : 하나님 / 모든 것을 끝내시는 분 : 하나님

### ◆핵심 정리

- •계시록은 이룰 예언

- •성취 때 기록된 예언대로 이루어짐 (오늘날 : 실상 계시 시대)

- •계 1:1-8 계시록 전장의 요약, 결론

- •계 1:9~ 계시록 사건의 시작 (대한민국 과천 소재 장막성전 1996년 시작)

## 9-11절 : 성령의 감동

### 1) 성령의 감동

- ·요한 : 인명을 빙자한 비유(호 12:10) → 계시록 성취 때 “새요한”

- ·주의 날 : 주님이 나타나신 날(주의 역사가 시작된 날)

- ·성령의 감동 : 성령의 감동으로 이상을 본 것(슥 4:1)

- ·나팔소리 같은 음성 : 예수님의 음성

- ·밧모섬 : 지명을 빙자한 비유 → 계시록 성취 때 “장막성전“

## 12-16절 : 일곱 금 촛대와 인자 같은 이

### 1) 일곱 금 촛대와 인자 같은 이

- ·금 촛대(렘 52:19) = 순금 등대(모세 때 장막에서 사용하던 기구)

- ·일곱 금 촛대가 있는 곳 : 일곱 순금 등대가 있는 ‘하나님의 장막‘

계시록 사건이 시작되는 현장(=장막성전)

- ·인자 같은 이 : 성령체이신 예수님(계2-3장 참고)

요한이 예수님을 못알아 본 이유 : 2천 년 전 예수님의 육체의 모습과 달라진 성령체의 모습이었기 때문

### 2) 좌우의 날 선 검

: 배도자와 멸망자를 심판하는 “하나님의 말씀”(마 10:34, 엡 6:17)

## 17-20절 : 대언의 목자와 일곱 별의 비밀

### 1) 기름 부음 받는 요한

- ·엎드러진 이유 : 두려운 마음이 들었기 때문

- ·오른 손을 얹음 : 성령의 기름을 부어 택한 목자로 삼으심

: 이 때부터 “새요한”으로서 사명 시작

*예수님이 새요한에게 하신 일 : ①일곱별에게 편지하라 지시 ②새요한에게 안수하고 택하심

### 2) 사망과 음부의 열쇠

: 지옥문을 여닫을 수 있는 지혜(시 119:130, 계 9:1, 계 20:1-8)

### 3) 본 것과 이제 있는 일과 장차 될 일

- ·본 것 : 예수님의 형체와 일곱 별과 일곱 금 촛대

- ·이제 있는 일 : 일곱 교회가 당하고 있는 현실, 사단(니골라당)의 미혹 사건

- ·장차 될 일 : 이김으로 계2-3장의 약속한 복을 받음

### 4) 일곱 별과 일곱 금 촛대의 비밀 (배도의 비밀)

- ·비밀이라 하는 이유 : 요한계시록에 예언한 ‘배도한 장막과 배도자’임을 세상 목자뿐 아니라 당사자인 일곱 사자들도 모르기 때문.

- ·일곱별이 예수님의 손에 있었다는 것 : 예수님께서 일곱 사자를 들어 역사하심

- ·일곱 사자 = 일곱 별 → 이들이 있는 곳 : 일곱 금 촛대 교회 = 하늘 장막(계 13:6)

- ·일곱 별 : 길예비 등불의 역사 → 재림의 역사가 시작됨을 알리는 기호

(세례 요한 : 등불의 역사 → 예수님의 초림 역사의 시작을 알림)

### ◆핵심 정리

약 2천 년 전, 밧모섬에서 받은 요한의 환상 계시인 본문 계 1:9-20의 말씀은 약 2천 년이 지난 후 대한민국 과천 소재 장막성전에서 1977년에 실상으로 이루어짐.

예언은 실상을 증거하는 증거 서류로서 예언이 성취 될 때에 비로서 그 역할을 하게 됨. 그렇기에 계시록이 성취되는 오늘날 이 요한계시록의 예언의 말씀을 온전히 깨달아 참 하나님의 마지막 역사에 동참하여 영생과 나라와 제사장의 복을 받아 누리는 우리들이 되자
