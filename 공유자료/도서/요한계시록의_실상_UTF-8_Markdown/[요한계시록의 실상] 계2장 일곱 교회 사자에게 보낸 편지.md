- 성취 시기 : 배도한 일곱 금 촛대 장막의 일곱 사자가 침입자 니골라당과

하나되어 있을 때

- 출현 인물 : 영계 - 예수님의 영(성령)과 사단

성도들, 니골라당

- •편지를 보내는 자 : 예수님

- •편지를 받는 자 : 장막성전의 목자(성도들)

## 1-7절 : 에베소 교회 사자에게 보낸 편지

### 1) 첫 사랑과 촛대

- •처음 사랑을 버림 : 예수님을 버리고 배도 행위를 함

- •떨어진 것 : 예수님의 손 = 예수님과 말씀을 떠나 배도의 길을 걷고 있다는 것

- •촛대를 옮긴다 : 하나님의 영과 사명을 다른 사람에게 옮김(계 4:5참고)

### 2) 니골라당

- •니골라-유대교에서 예수교로 입교한 이방인(행 6:5)

이름의 뜻 - “백성의 정복자“, ”파괴자“

장막성전에 입교하여 사단의 교리로 교훈하며 당을 지은 거짓목자(오00)

### 3) 낙원에 있는 생명나무 과실

- •낙원 : 영계의 천국인 새 예루살렘 / 새 하늘 새 땅

(눅 23:42-46, 고후 12:1-4, 계22장, 계14장)

- •생명나무 과실 : 예수님의 생명의 말씀

### ※선악나무 : 거짓목자 → 사단의 교리 : 선악과(니골라당의 교훈)

- └ 먹는 자는 아담, 하와처럼 죽게 됨(마 7:15-16)

## 8-11절 : 서머나 교회 사자에게 보낸 편지

### 1) 자칭 유대인인 사단의 회

- •자칭 유대인 : 하나님을 믿는 참 백성으로 자신을 가장한 “멸망자”

ྠĀ (고후 11:14-15 참고)

- •사단의 회 : 장막성전을 멸망시킨 니골라당(7머리와 10뿔 짐승)

=청지기 교육원(실상)

### 2) 생명의 면류관과 둘째 사망

- •생명의 면류관(영광과 승리를 상징) : 영생

- •둘째 사망 : 육신이 죽은 후 그 영혼이 받게 될 지옥형벌

## 12-17절 : 버가모 교회 사자에게 보낸 편지

### 1) 발람의 교훈과 우상의 제물과 행음

- •사단의 위 : 사단의 보좌가 있는 곳(니골라당)

਼Ā 멸망당한 장막성전도 사단의 위가 됨

- •발람 : 구약 시대 이방 술사로서 드물게 하나님을 믿던 자(민22-24장, 벧후 2:15-16)

계시록 성취 때-장막성전 출신의 거짓목자 곧 니골라(오00)

- •발락 : 구약시대 모압 왕(멸망자 곧 계17장의 음녀/탁00)

### 2) 니골라당의 교훈과 예수님의 입의 검

- •니골라당의 교훈 : 멸망자가 사단에게 받은 교리

- •입의 검 : 말씀(엡 6:17)

### 3) 감추었던 만나

: 비유와 일곱 인으로 감추어 두었던 천국비밀의 말씀(신약의 예언이 성취된 실상)

### ※참고성구 : 출 16:31:35, 요 6:48-57,63, 눅 22:14-20

### 4) 흰 돌 위에 기록한 새 이름

- •흰 돌 : 성경말씀, 말씀을 예수님처럼 마음에 기록한 사람

(심판의 말씀=신약 성경의 말씀과 말씀을 받은 새 요한)

- •새 이름 : 예수님의 새 이름(계 3:12참고)

## 18-29절 : 두아디라 교회 사자에게 보낸 편지

### 1) 여자 이세벨과 행음한 종들

- •이세벨 : 이방 시돈 왕 엣 바알의 딸로서 아합 왕의 아내가 됨(왕상 21:25)

이스라엘에 이방종교를 유행시킨 악녀

계시록 성취때-니골라당을 주관하는 머리된 목자 곧 음녀(계17장)

- •영적 행음 : 하나님의 영과 교제해야 할 성도의 영이 사단의 씨인 비진리를 받으며 사단의 영과 교제하는 행위(호 2:19, 고후 11:2참고)

- •행음하는 종들 : 일곱 금 촛대 장막의 목자와 성도들

### 2) 침상과 큰 환난

- •이세벨이 던져질 침상 : 둘째 사망(계 20:12-15)

- •일곱 금 촛대 장막이 받을 환난 : 계시록 전장에 기록된 재앙(계6,8,9,16장)

### 3) 사망으로 죽는 자녀

:멸망자와 하나가 된 일곱 금 촛대 장막의 성도들

- →하나님을 떠나 사단에게 속한 자를 심판하시는 하나님(계 6:8)

### 4) 두아디라에 남은 자와 사단의 깊은 것

- •사단의 깊은 것 : 사단의 지혜와 비밀

- •사단의 깊은 것을 알지 못하는 자들 : 멸망자의 사단의 교훈으로 가르침을 받지 않고 사단과 하나되지 않은 소수의 장막 성도들

### 5) 만국을 다스리는 철장 권세와 새벽별

- •철장(쇠지팡이, 홀) : 영원한 치리권과 진리의 말씀(시 2:8-9, 계 12:5)

- •새벽별을 주심 : 예수님께서 장가들어 함께 하심
