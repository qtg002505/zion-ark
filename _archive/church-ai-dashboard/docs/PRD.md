# 제품 요구사항 문서 (PRD)

MVP 범위 기준. 각 기능은 별도 스펙(`docs/features/<name>.md`)으로 확장한다.

---

## F1. 인증 & 권한

- Supabase Auth (이메일 + OAuth 카카오 우선)
- 역할: `pastor` / `admin` / `leader` / `member`
- 최초 가입자는 `member`, 관리자 승격은 `pastor`/`admin`만 가능
- RLS: 모든 테이블에 역할·소속 교회 기반 정책

## F2. 성도 관리

- 필수 필드: 이름·성별·생년월일·연락처·주소·직분·소속 소그룹·가족 관계
- 검색·필터 (이름·직분·소그룹·연령대)
- 엑셀 임포트/익스포트
- 개인 프로필 페이지 (본인 편집 가능 범위 제한)

## F3. 출석 관리

- 예배(주일 오전/오후·수요·새벽) · 소그룹 모임별 출석 체크
- 태블릿용 대량 체크 UI
- 개인별 출석률·연속 결석 알림
- 월간 통계 (직분별·연령별·소그룹별)

## F4. 헌금 관리

- 종류: 십일조·감사·주정·선교·건축·기타 (교회별 커스텀)
- 개인별·주별·월별 집계
- **본인 + 재정 담당자만 조회 가능** (RLS 엄격)
- CSV 익스포트 (세무 신고용)

## F5. 소그룹 게시판

- 그룹별 공지·기도제목·나눔 게시글
- 댓글·좋아요
- 기도제목은 응답 여부 체크
- 리더가 목회자에게 리포트 공유

## F6. AI 어시스턴트

- **설교 도우미**: 본문·주제·대상 입력 → 아웃라인·예화·적용점 제안
- **성경 리서치**: 구절 입력 → 원어·주석·병행 구절 요약
- **심방 노트 요약**: 자유 텍스트 입력 → 요점·후속 조치 정리
- 모든 응답은 초안이며 편집 후 저장 필요 (사용자 검토 강제)
- 호출 로그·토큰 사용량 대시보드

## F7. 대시보드 홈

- 역할별 위젯 (교역자: 이번 주 출석·헌금·심방 리스트 / 성도: 본인 출석·다음 모임)
- 최근 알림·공지

---

## 우선순위 (구현 순서)

1. F1 인증 + 기본 성도 CRUD (F2 일부)
2. F3 출석 (핵심 사용 시나리오)
3. F4 헌금
4. F5 소그룹 게시판
5. F6 AI 어시스턴트
6. F7 대시보드 위젯 완성
