# 프로젝트 개요 — church-ai-dashboard

## 한 줄 정의

교회 운영진과 성도가 한 곳에서 **행정 데이터를 관리**하고, **AI로 사역 업무를 보조**받고, **소그룹 단위 소통**을 할 수 있는 통합 대시보드.

## 왜 만드나 (문제)

- 교회 행정은 여전히 엑셀·수기·카카오톡·밴드에 분산돼 있다.
- 담임/부교역자는 설교 준비·심방 노트·주보 작성에 반복 작업이 많다.
- 소그룹(구역·목장·셀) 리더는 출석·기도제목·나눔을 따로 수집한다.
- 기존 교회 관리 SW는 UI가 낡고, AI 기능이 없거나 서구권 전용이다.

## 누가 쓰나 (사용자 페르소나)

| 역할 | 주요 니즈 |
| --- | --- |
| **담임/부교역자** | 설교 초안·성경 리서치·심방 노트 요약, 주간 리포트 확인 |
| **행정 간사** | 성도 명부·출석·헌금·재정 입력/조회, 통계·보고서 출력 |
| **소그룹 리더** | 그룹원 출석·기도제목·나눔 기록, 목회자와 공유 |
| **일반 성도** | 본인 헌금 내역·출석 확인, 소그룹 공지·기도제목 열람 |

## 범위 (MVP)

**포함**
- 성도 명부 CRUD (기본 정보·가족 관계·직분·소속)
- 출석 체크 (예배별·소그룹별)
- 헌금 기록·집계 (개인/전체, 월별 리포트)
- 소그룹 게시판 (공지·기도제목·나눔)
- AI 어시스턴트 (설교 초안 도우미, 성경 구절 검색·해석 요약)
- 역할 기반 권한 (교역자 / 행정 / 소그룹 리더 / 일반)

**제외** (v2 이후)
- 실시간 채팅 / 화상 예배
- 온라인 헌금 결제 (PG 연동)
- 모바일 네이티브 앱
- 다국어

## 성공 지표 (초기 3개월)

- 활성 교회 1곳 이상에서 정기 사용
- 주간 활성 사용자(WAU) 30명 이상
- 성도 데이터 500건 이상 등록
- AI 어시스턴트 주간 호출 20회 이상

## 비기능 요구사항

- **보안**: RLS 강제, 개인정보(주민번호 등) 저장 금지, 헌금 데이터는 본인·행정만 조회
- **성능**: 대시보드 초기 로드 3초 이내 (성도 1000명 규모 기준)
- **접근성**: WCAG AA, 시니어 사용자 고려한 폰트·버튼 크기
- **데이터 보관**: 백업 일 1회, 30일 복원 가능
