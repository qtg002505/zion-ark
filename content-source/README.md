# content-source — 원본 자료 투입 폴더

강의·자료 원본 파일을 여기 하위 폴더에 넣으면, 개발 세션이 `src/content/*.ts`로
변환해 사이트에 탑재한다. **원본은 수정하지 않고 그대로 보관** — 교리 내용 재작성 금지,
변환 시 제목·장 번호·깨진 문단 정리만 한다.

## 폴더 구분

| 폴더 | 넣을 것 | 탑재 위치 |
| --- | --- | --- |
| `lectures/` | 표준 강의 교안 (초등 23강 원문, 중등·고등 확보 시) | 강의 교안 화면 (`src/content/lessons.ts`) |
| `class-materials/` | 분반·보강 자료 | 자료실 › 분반·보강 자료 |
| `series/요한계시록/` | 요한계시록의_실상 마크다운 (양식.md 제외) | 시리즈 리더 (`src/content/revelation.ts`) |
| `series/천지창조/` · `series/예그행/` | 해당 시리즈 원본 (예그행은 기준 소스 결정 후) | 시리즈 리더 |
| `quotes/` | 총회장님 어록 파일 | 어록 검색 (`src/content/` 시드) |
| `enneagram/` | 에니어그램 가이드 원문 | 에니어그램 화면 (`src/content/enneagram.ts`) |

파일 형식은 md·txt·docx·xlsx 무엇이든 됨 — 변환은 개발 쪽에서 처리.

## 절대 규칙

- **수강생 개인정보(명단·출결·상담 원문) 파일은 이 폴더에 넣지 않는다.**
  이 폴더는 git에 올라가는 전국 공통 교육 자료 전용이다.
- 개인정보가 섞인 파일은 리드에게 별도 전달 경로 확인.
